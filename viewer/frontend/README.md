# 动作审计前端

React 19 + Vite + Three.js。此目录只包含网页、构建依赖和协议测试；应用启动/停止与只读数据适配器见项目上层 README。生产服务由后端提供 `dist/`，只访问同源 `/api`。

## 构建
```sh
npm ci --cache .npm-cache --no-audit --no-fund
npm run build
node --test src/api.test.js src/geometryMath.test.js
```
本地可选开发服务：`npm run dev -- --port 5173`，只绑定127.0.0.1；开发代理默认后端127.0.0.1:8765。不要用此命令替代生产进程寿命控制。

## 模块
- `src/api.js`：版本化二进制解码与明确HTTP错误；不支持float16几何。
- `src/useMotion.js`：固定SHA快照、取消过时请求、15秒过期检查，暂停/拖动80ms防抖单帧，播放32帧块及一个下一块预取；每视图最多4块或64MiB缓存。关键坐标均Float32。画面/条带指针使用实际已显示帧；等待目标帧时明确显示缓冲。
- `src/geometryMath.js`：数值矩阵入口兼容源描述中的嵌套3×3和flat旋转，非有限数值拒绝；真实ScoccerBall_A_1描述保存在`.qa/source-object-descriptor.json`并参与矩阵组合回归测试。
- `src/Viewer.jsx`：真实MJCF geom-local网格和点，经geom世界位姿变换。人体点已由后端校准，前端不再次减地面。接触绿/橙取源点位标签；红是当前几何穿透距离，黄是源人体区域接触且机器人当前几何区域最小间隙1–20mm。人体点绿色需要源区域接触与界面现算点高0–1mm。物体局部速度箭头转回世界方向；最多96支、显示长度上限20cm。原始视图仍展示修正后源标签，始终警告。骨架来自joint_pos和joint_body最近有joint的祖先连线。
- `src/Timeline.jsx`：13区 × 四组完整相同时间轴。每个像素列聚合对应帧段的任意接触/诊断峰值，保留异常尖峰；点击条带定位到该列对应帧，可用逐帧控制继续检查。曲线分别显示选区地面间隙、选区地面速度、三类最大穿透及源flags。
- `src/Inspector.jsx`：仅明确人工按钮或Ctrl+Enter提交；A/R/F只选择判决，I/O选择闭开帧段，可组合多个。所有POST带X-Audit-Request:1，不自动重复已commit的请求。
- `src/Dashboard.jsx`：当前hash有效的整条判决统计，局部判决另列。Wilson区间只用真正入队的sample_kind=random，界面随机浏览不改变抽样身份。
- `src/App.jsx`：比较页每页最多6台机器人，各页保持同一来源时间；当前页全体加载完成才推进播放，避免超过浏览器WebGL上下文限额。

## 精度与证据
位置、旋转和关键几何用Float32，不用Float16。协议测试覆盖米级位置1.00005m与-0.00051m穿透边界，误差低于0.1µm；完整FK/编码误差验证由后端测试负责。UI不改源数据，也不将几何诊断写回源标签。

帧率来自文件：踢球样本约90.0009Hz，与规格30Hz不同，显示警告并按真实fps计算时间。带宽不足时播放会缓冲，不能把指定1×当作持续墙钟1×。应用内同时给出目标帧和保留画面帧。
