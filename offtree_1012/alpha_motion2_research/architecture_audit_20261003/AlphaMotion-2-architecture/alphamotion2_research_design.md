# AlphaMotion-2：骨架与表面联合建模的候选设计

状态：研究方案，尚未实现或训练。本文固定已经明确的建模目标；网络宽度、层数、量化方式、生成器与损失权重仍是待实验选择，不能由示意图冒充最终 config。

## 研究假设与具体任务

核心假设是：局部表面区域的几何与文本语义可以共同建立跨本体的共享对应，使未见过的本体在提供自身几何与区域描述后，也能使用同一套已训练权重完成 surface retargeting。这里的文本条件是“左掌接触面”“指腹”“夹爪内侧接触面”等局部语义；它与“拿起杯子”等描述整段动作的文本条件分别编码。纯表面路径具有独立研究价值，不能预先假设它必须依赖骨架才能泛化。AlphaMotion-2 完整模型则明确采用 skeleton + surface 联合预训练。

以人手把杯子递给夹爪为例，共享内容可以是物体相对接触位置、接触法向、闭合方向和时序；目标机器人如何通过自身关节实现这些关系，由目标几何和运动学约束决定。“拇指”与“夹爪第一片”不必一一同名。区域语义应同时保留解剖部位、左右侧、局部朝向和接触功能，允许一对多、多对一以及无对应区域。文本先验帮助提出对应，几何和任务监督决定对应是否有效。

## 输入接口与可复用数据

本体描述 D 包含：规范姿态骨架、父子拓扑、关节轴与范围；规范姿态网格、三角面、法向和面积；网格到刚体或关节的绑定；局部区域标识、区域描述及其文本嵌入。必须保留实际米制尺度，并另给归一化尺度，防止模型丢失厘米级接触精度所需的信息。

运动描述 X 包含：根部 SE(3)、关节状态、时间戳与有效帧；由同一运动学状态计算的关节位置及姿态、表面点及法向；接触标签、场景或物体几何与各字段的有效性。表面样点保存规范 mesh face ID 和 barycentric coordinates，跨帧追踪相同物质点；不能每帧独立重采样后把不同顶点误当同一点的速度。

AlphaMotion-1 的 LAFAN/AMASS 多本体缓存先作为骨架通路的训练资产。机器人表面可以由可用的 mesh、刚体绑定和相同关节运动经 FK 生成。UniMate 的训练特征缓存不是完整 mesh 缓存，但其原始 rig 与现有 skin 提取/LBS 工具可用于派生表面序列。每条样本必须标记 observed、derived、pseudo 或 missing；若缺少 mesh 或有效绑定，表面损失 mask 为零，不能用零填充值伪造完整监督。

人体皮肤变形与刚体机器人表面应走各自的几何适配器。若只根据骨架拟合出人体 mesh，拟合结果属于派生或伪监督，不能称实测接触。缺少物体、灵巧手或触觉记录的样本不能凭网络接口被计为具有这些标签。

## 神经结构：双路编码、共享语义与目标条件解码

骨架 token 由局部/全局运动特征、骨架几何、DOF 描述、部位文本嵌入组成。保留 AlphaMotion-1 的拓扑距离偏置思想，同时加入时序建模。表面 token 由局部点集编码器得到，包含规范姿态与动态位置、法向、面积、区域文本嵌入和可用接触条件；先把密集点压缩成局部 patch，避免把所有点逐帧铺平成全局注意力序列。

骨架内部注意力使用运动学拓扑；表面内部注意力使用局部邻域或测地邻域。两路之间使用 mesh–link/skin binding 支持的交叉注意力，并可叠加语义相似度。两路共同进入共享运动表示，但 surface 分支在结构上保留独立的输入、对应预测和输出，供纯表面实验使用。不要先把点附着到关节、再将关节名当作唯一表面信息，否则无法检验局部表面语义是否带来新增能力。

建议先实现共享权重的跨本体对应模块，输入源/目标的几何与区域语义，输出软对应及无匹配置信度。可以比较注意力对应与允许非等质量的 transport matching。目标是推断新目标的对应；UMR 的逐机器人静态重训练可作为对照或教师，不是该模块在新本体上的必经步骤。

目标解码器查询目标骨架与目标表面描述。候选主路径先输出目标合法关节参数与根部状态，再通过目标 FK 和刚体变换/LBS 得到表面；另设表面对应/接触预测头并用一致性约束连接两者。这样 surface 会直接参与表示与训练，而最终几何仍可追溯至关节状态。也可实验自由表面预测再投影到可实现关节运动的变体，需单独报告投影带来的误差和计算时间。

用于 generation 的全局动作文本、已有运动片段、SE(3) 末端目标、物体与接触条件通过独立条件接口注入共享时序生成器。局部部位文本回答“这个区域是什么、如何接触”，动作文本回答“要做什么”。触觉接口预留 sensor-to-surface binding、局部坐标系、时间戳、压力/力特征与有效性 mask；当前无触觉数据时该通路明确缺省，不声称已学会触觉。

## 计算草案

e_j = P_joint([motion_j, geometry_j, dof_j]) + P_sem(E_text(part_text_j))

e_p = PointEncoder(local_points_p, normals_p, area_p) + P_motion(surface_motion_p) + P_sem(E_text(region_text_p))

A_sp = softmax(Q_surface K_skeleton^T / sqrt(d) + B_binding + B_semantic)

Z = SharedTemporalEncoder(JointEncoder(e_j), SurfaceEncoder(e_p), A_sp)

C_source,target = CorrespondenceHead(D_source, D_target, Z, valid_regions)

(q_target, root_target) = TargetDecoder(Z, D_target, conditions)

V_target = GeometryAdapter(q_target, root_target, mesh_target, binding_target)

这些公式表达模块关系，不固定 token 数、层数或融合位置。B_binding 在绑定缺失时必须有明确可用性处理；局部语义的相似度权重必须通过实验确定。纯 surface 变体可直接输出目标表面关系或轨迹；若要驱动物理机器人，仍需一个将轨迹实现为目标可行运动的接口。这不限制纯表面对应模型本身的泛化假设。

## 预训练与生成器比较

阶段 A：静态几何与局部语义对应。参考 UMR 的规范模板重建、覆盖、邻域保持与防塌缩思路，但训练跨本体共享网络。区域语义监督、几何增强、同一表面的不同采样一致性与跨视图一致性可并用；Chamfer 本身不保证语义一致，也不能仅因两个表面重合便判定左右侧和指尖对应正确。

阶段 B：骨架与表面的同步运动预训练。用统一时间戳和同一 FK/LBS 状态构造双路输入；训练重建、遮挡补全、跨本体映射、表面对应与关节—表面一致性。接触、非穿透和时序项仅在对应场景及标签可用时启用。人体和机器人之间没有可验证 dense correspondence 的数据，不伪造逐点真值，可使用区域级、关系级和几何循环约束。

阶段 C：动作生成与约束补全。优先把生成器视为共享表示上的可替换模块，比较 flow matching 与 diffusion；FSQ 是表示量化选择，能够与二者组合。首轮控制变量应区分“连续表示 vs FSQ 表示”和“flow vs diffusion 生成器”，保持数据、编码器/解码器容量及训练预算可比，同时报告采样步数、模型函数评估次数与实际延迟。

阶段 D：本体条件的执行反馈。共享运动语义不等于所有本体共享动力学。对 locomotion 和 manipulation 分别做目标机器人跟踪、接触与物体交互评估，再把失败片段、可执行性标签与修正轨迹返回数据清洗和训练。离线几何或逆动力学检查、仿真闭环、实机实验分别留存证据。

候选总损失为 L = L_motion + λ_s L_surface + λ_c L_correspondence + λ_k L_joint-surface + λ_r L_contact + λ_t L_temporal + λ_g L_generation。每项均乘标签有效性 mask，并按有效元素数归一化；各 λ、距离单位与点采样密度的影响必须登记。此处是目标分解，尚未选定最终损失形式或数值。

## 验证核心 thesis 的最小对照

S0：骨架模型，保留部位文本；S1：纯表面模型，不加局部区域文本；S2：纯表面模型，加入局部区域文本；S3：骨架+表面，保留骨架文本但移除局部区域文本；S4：完整联合模型。S1 与 S2 检验纯表面语义增益；S0 与 S3 检验几何表面增益；S3 与 S4 检验联合模型中的局部语义增益。对照尽量匹配数据、训练预算与容量，避免把模型规模变化解释为语义作用。

为了确认模型利用的是可迁移语义，额外比较同义改写、区域文本打乱、同义不同名称与功能相近但解剖不同的末端执行器。新本体可使用自身几何和预先定义的区域描述；记录描述的来源与人工成本。动作序列和完整本体的训练/评估划分复用基础工程已有索引，细粒度实验协议另存，不把划分脚本本身当作泛化结果。

映射需同时测量骨架位置与旋转、表面距离与法向、接触保持/穿透/滑移、末端 SE(3) 误差及运行时间。手部与夹爪记录任务成功率和物体状态，不能仅看全身平均关节误差。生成需另测条件遵循、运动质量与多样性。与 UniMate 的同数据同任务对比用于证明映射/生成能力；新增表面和接触任务需报告基线适配方法，避免宣称原模型没有直接输出的量就是零分。

## 代码依据与状态边界

AlphaMotion-1：本轮核对真实 exp_topo/DualTranslator 及线上 megatron 对应 config；不是 alpha_motion2 目录中的空模型脚手架。配置 d=256，heads=8，encoder=4，decoder=4，position slots=4，rotation slots=128，FSQ stages=1，每槽 13 个标量等级配置为 32，SigLIP 文本维度 768，geometry+DOF 输入维度 34。root_head=false；root_pos 只对位置头根槽的第一维施加高度监督。contact 模块存在不等于该权重训练了接触 BCE 预测头；实际 w_cbce=0。

UniMate：本轮固定公开提交 2c5b384715aa63d8639b1ed7eb74bfe614570c7a，采用 graph_adaln 60 帧配置解释主图，并在附录列出 full_cross_attn 变体。UMR：本轮固定公开提交 d1cdaedaf67a827198da71c5fa831f48b2e51f91，区分 PointNet 对应学习、表面绑定与受约束优化。UMR 的浏览器 demo 默认执行真实 WASM 对应训练和优化；UniMate 核查的公开 interactive 页面主要是模型结果动画回放，两者可复用的边界不同。

上述设计的贡献是一个待验证的研究主张。尚无 AlphaMotion-2 已训练权重、优于 UniMate 的结果、跨末端执行器成功率或 sim2real 完成结论。
