# Transformer-style model review

This review contains only UniMate and AlphaMotion-1: one overall path and one expanded-block page per model. The architecture style is inspired by classic Transformer diagrams; operations, normalization order, conditions and dimensions follow the audited implementations.

- Transformer-style-models-review.pdf: four standalone vector pages.
- unimate/ and alphamotion1/: editable SVG, vector PDF, 240 dpi PNG, reproduction scripts and source maps.
- google-docs-review.pdf and AlphaMotion-2-review-editable.docx: current team document exports, including the contact representation scope addendum.
- root-final-qa.json: rendered checks. The diagrams and addendum have been saved and read back in the existing team document.

Google Docs review tab: https://docs.google.com/document/d/1gH9WaPSgqUcTdrPYeBCNaLkWrVoG0qzNsiJLPVsniBU/edit?tab=t.5mjk4rn6kptl

AlphaMotion-2 architecture options remain experimental. No formal pretraining or performance claim is represented by these artifacts. The two remaining model redraws require user style feedback first.
