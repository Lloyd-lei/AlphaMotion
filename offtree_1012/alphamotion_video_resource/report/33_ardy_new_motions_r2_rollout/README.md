# 33 · ARDY 新动作 → Megatron → 五台机器人：R0 裸解码 vs R2 递推精修（0924）

源：ARDY-G1（ARDY-G1-RP-25FPS-Horizon52）现生成 5 条新 prompt，8 秒，seed 0，25 fps。链：ARDY npz → 36 节点 G1 谱 pose9（接触通道 = ARDY 脚接触标签）→ Megatron 编码 → 解码到 G1 / H2（30 节点 H2_loop 骨架，同 report 31）/ A3（零样本，不在训练缓存）/ GR3 / Adam → 投影 → 两臂：**R0** = 今天的路径（贪心 + LM25，解码器根高，不修正，穿地原样显示）；**R2** = report 31 的递推 LM（上一帧热启动 + AR(2) 先验 + 接触闩锁钉脚 + 根高由闩住的脚反推，每帧 2 步，常数全部按 report 31 的推导实测）。消融 **R2f** = R2 + 接触概率下降沿提前松闩。

本轮相对 report 31 的一处口径改动（对五台都适用）：脚的几何改用厂商 MJCF **碰撞几何**、取脚节点整个子树（GR3 左脚底在 roll 子连杆、A3 在 roll 子连杆、Adam 在 toe 子连杆；report 31 用的是脚节点自身的视觉网格，在 GR3/Adam 上高估脚底 10 cm）。尺子同样按子树取最低碰撞点。foot_hulls.json 记录每台用到的连杆和中性位脚底落差。

视频：per_clip/ 每条 prompt 每台机器人一段，左 R0 右 R2，sajio 渲染链（绿 = 贴地 1 cm 内，红 = 穿地），prompt 烧在底部；grids/ 每段 12 帧网格。

## 判决（先看网格，再看数字）

**R2 在五台机器人上都把脚放回了地面，姿态一根手指头没动。** 25 张 12 帧网格我全部看过（grids/）：
- **G1**：R0 只有轻微穿地（跑步落脚、深蹲底部脚底发红，max 2.5 cm），R2 全程绿；两边姿态逐帧一致。滑移 p50 3.7 → 5.3，开合跳 34 → 0，跑停 17 → 9。**深蹲是反例**：p95 17 → 45，闩锁在双脚全程着地的深蹲里抖动（左脚 64 次开合、右脚从未闩住：脚高差超出噪声带、脚速超出源的接触速度门），ruler 看到的大滑移在起身那 15 帧（60～70 cm/s，R0 也有）。
- **H2**：R0 每一帧脚都是红的（脚在地下 6～15 cm，深蹲 14.6 cm），R2 脚贴地、无红；姿态不变。滑移 p95 中位 47 → 29，开合跳 16 → 0，跑停 48 → 11。
- **A3（零样本）**：R0 脚在地下 10～31 cm，整段红；R2 归零。滑移从荒谬的 136 降到 26（走转身 391 → 26，跑停 136 → 7）。A3 站姿本身略外八、手臂张开，R2 没有改它。
- **GR3**：R0 悬空 4～8 cm（脚下没有任何上色，滑移 0 是因为从没进站立相），R2 落地、脚绿；驼背屈膝的姿态原样保留（这是解码器的账，不是精修器的）。落地后滑移才可测：p95 中位 19。
- **Adam**：R0 悬空 4～7 cm，R2 落地脚绿；深蹲弯腰前倾姿态两边一致。落地后滑移 p95 中位 21。

数字上的三条线：穿地五台全部归零（max ≤ 0.4 cm，穿地帧占比 0）；姿态位移中位 0.0～0.4 cm（深蹲 G1 1.9 cm 是闩锁抖动付的）；每帧 6.3～9.3 ms，因果，25 fps 预算用了两成。接触 F1 对 ARDY 标签在 G1 上 R0/R2 0.94/0.75，其它机器人 R0 因为悬空或穿地 F1 无意义，R2 之后 0.6～0.9。

**没修好的**：(1) 双脚全程着地的慢动作（深蹲）里闩锁抖动，需要一个更稳的"在支撑"判据，比如把源的接触标签当先验或把噪声带按脚高分布量；(2) GR3 驼背、A3 外八这种姿态偏置，精修器按设计不碰，要在解码器侧解；(3) ARDY 对 prompt 的服从：开合跳只做了一次就站住，深蹲只蹲了一次并且蹲到 7.5 秒才起，"两次"没有执行；跑停在 2 秒内跑完，剩下 6 秒站着。

**R2f 消融**：下降沿提前松闩对结果没有可测变化（见下表），不采用。

## 计时
