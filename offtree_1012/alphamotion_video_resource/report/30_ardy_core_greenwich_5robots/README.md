# 30 · ARDY **Core**（人体 27 关节，20 fps）→ Megatron → G1 / H2 / A3 / GR3 / Adam，对照 report 29（ARDY G1 源，25 fps）

同样 5 条长 prompt、seed 0、10 秒。NVIDIA 只发布了 Core 和 G1 两个 ARDY 权重，**没有 SOMA 权重**，所以"两种人体数据"只能做 Core 这一种。

流水线：ARDY-Core-RP-20FPS-Horizon40 → cskel27 全局旋转 + 位置 + 脚接触 → 我们的 SkeletonSpec（offsets 取 ARDY neutral joints，球关节，FK 复现 posed_joints 0.000 cm）→ Megatron 编码（接触通道喂 Foot/ToeBase）→ 解码 5 台 → LM 投影 → 考卷 + 几何扫描 + 计时 → 我方渲染（own_render，六联含人体棍图，根按穿地量抬起显示）+ sajio 渲染链（sajio_render，原始根高不抬，绿贴地红穿地）。
Megatron 没见过 cskel27 这套骨架和关节名（训练人体是 human_smpl 22 关节），8 个新名字现算 SigLIP 嵌入。

文件：`{p}_result.json` 每 prompt 考卷；`results_all.json`；`greenwich_timing.json` / `ardy_timing.json`；`bias_scan.json`（碰撞几何最低点）/ `bias_scan_visual.json`（视觉网格最低点，两者一致）；`robot_npz/`（每台关节角、根）；`{p}_ardy_core.npz`（ARDY 源）；脚本 gen_core.py / ardy_core_in.py / pipe_core.py / sajio_render.py / bias_scan*.py。

## 网格里看到的
五台机器人在每段都跟着人体棍图的节奏：搬箱段弯腰（GR3/Adam 也弯到位）、跨栏段起跳腾空、挥手、踢腿、坐下再站起。Core→G1 的坐姿是双腿前伸不是盘腿。GR3 依旧驼背屈膝且悬空，Adam 悬空但姿态正常。H2 这次几乎踩到地面（偏置 ≈ 0），A3 仍穿地 7–10 cm。
