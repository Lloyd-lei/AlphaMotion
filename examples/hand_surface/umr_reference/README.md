# SMPL-X to G1 hand-surface reference assets

These figures show real existing geometry in two independently constructed static reference scenes. UMR optimization, motion transfer, dexterous control, force and tactile inference were not run. The images are reference material for a surface-interaction explanation.

Use `smplx_left_palm_surface_overlay.png` and `g1_left_palm_surface_overlay.png`; transparent variants, mesh-only images and 720px palm crops are included. Orange is the selected body surface point. Teal is the closest point on the sphere. The orange arrow is d = body_surface - sphere_closest_point, pointing from object to body. Purple is the actual local triangle-winding normal. Markers remain visible through surfaces for readability; their image coordinates are the actual camera projection.

Both spheres have radius 0.03 m and world-from-object rotation I. Their centers are independently placed next to each selected hand point. Both selected-point signed gaps are 0.012 m, so `contact=false` under abs(gap)<=0.002 m. `valid_geometry=true` means the point/triangle/sphere computation is well-defined. It is not force, tactile or physical-contact evidence. Whole local meshes were also checked against the sphere; neither sphere intersects the rendered hand mesh. That audit is separate from the selected-point contact flag.

SMPL-X uses the existing `SMPLX_NEUTRAL.npz` numeric v_template/f/J_regressor/kintree/weights arrays. No model download, smplx package installation, blendshape posing, LBS, shape fitting, or subject-motion association occurred. The hand crop uses the real left-wrist/finger skin-weight family. The skeleton has real regressed wrist and 15 finger joints. The original template is in meters; world origin is its left wrist and world-from-model rotation is I. The crop has an open boundary. The palm-side selection is a transparent geometric heuristic, not an output of a learned surface-region labeler.

G1 uses actual `left_rubber_hand.STL` and the fixed `left_rubber_hand` body from the existing GMR G1 MJCF. World equals that link's local frame. It has zero finger DOFs; this is a fixed rubber hand, not a dexterous hand. The only blue edge joins the real wrist-yaw parent origin to the fixed hand origin. The STL retains duplicate vertices and is not treated as a watertight signed-distance volume. Triangle normals are source-winding normals. Sphere signed distance is analytic and does not depend on assuming a watertight hand.

`surface_reference_manifest.json` includes original triangle IDs, pinned source hashes, barycentric weights, local/model/world/object coordinates, normals, sphere closest point, d, gap/masks, camera/pixels, crop boxes and limitations. `surface_reference_trace.npz` contains only the small derived numerical sample. No source model, original mesh or remote OBJ rendering subset is copied locally.

Rebuild on lloyd with `/home/arenalabs/miniconda3/envs/ardy/bin/python build_reference.py` and `MUJOCO_GL=egl PYTHONDONTWRITEBYTECODE=1`. The script imports the previously validated case camera helper; its absolute path and SHA256 are in the manifest. Original assets and a small named-joint reference must remain accessible. Existing SMPL-X model-license acceptance was not revalidated; the official license URL is recorded. The GMR software MIT license does not independently establish an asset-specific Unitree mesh license. This package distributes derived pictures and numerical traces only.
