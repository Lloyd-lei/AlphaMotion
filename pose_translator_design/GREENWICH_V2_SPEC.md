# Greenwich-v2 规格:接触感知的运动学码本(0830)

目标:数据量与现 Greenwich 持平,参数 +2% 内(18M 肘部结论仍适用);把"接触"烙进码本而非外挂损失。
背景判决:GW 数据臂 vs 原生数据臂(BFM 引擎,同配置)中期 EMD 1.24 vs 0.94、地面段缺失 —— 汇率税的来源即 v2 的靶。

## 1. 接触四元组(每末端每帧;lloyd 0830 定稿的传感器接口)
| 通道 | 定义 | 编码 |
|---|---|---|
| gap | 到最近环境表面的符号距离 | asinh 翘曲 + FSQ 8 级(贴地毫米级,远处粗)|
| 接触位 | gap≈0 且相对表面切向静止(低且慢+滞回,常数物理来源)| FSQ 2 级 |
| 法向 | 接触面法线,**末端自身坐标系** | FSQ 8 级 ×2(球面参数)|
| 切向滑速 | 相对表面切向速度 | FSQ 8 级 |
- 力不进码(mocap 无监督,不编造);v2.1 候选:CoM 投影支撑权重。
- 根高改存「离当前支撑面高」,gauge 病(Adam 47cm/回家量规)一并治。
- 为什么这样定:三代填表人(几何标注器→物理引擎→触视觉皮肤)输出同构,接口一次定死;
  非平地(楼梯/跑酷/扒墙)天然良定义 —— 接触是「与最近表面的关系」,不是「与地面的高度」。

## 2. 架构
- **保留槽位**:256 latent 中固定划出 grounding 通道(如 250-255),自带 FSQ 维;禁止涌现分配
  (LLM 词表要求固定位置=固定含义;且给下游「单独操纵接触」的把手)。
- 编码器输入追加接触特征(标注器产);解码器双头:姿态头(现状)+ 接触头。
- **一致性损失(“aware”的全部机关)**:
  L = 1[踩]·(|FK_gap(q̂)| + ‖FK_切速(q̂)‖) + 1[空]·relu(ε − FK_gap(q̂)) + relu(−FK_gap(q̂))
  平地 FK_z,带场景升级为可微 SDF。梯度经 FK 回流码本:说踩必须真踩,说空必须真空,永不穿模。
  没有它,接触码只是装饰;没有槽位,一致性无把手 —— 两者缺一不可。

## 3. 监督管线
AMASS+LAFAN 全量过修复版接触标注器(低且慢+滞回+去毛刺,0829 修的那个;
无场景数据:接触位/滑速可标(免几何),法向掩码)。

## 4. 验收(先立线)
- 解码 LAFAN→G1:穿地 p95 <1cm、支撑相滑移 <0.15 m/s、高频颤动比 <1.15×(现 1.43×);
- **终审**:v2 解码数据喂 BFM(同配置),EMD 达到原生数据臂的 90% 以内 = 汇率税可忽略 = 平台主张成立。

## 5. 与精修器 A 的关系
A 是 v2 落地前的桥(离线数据管线用);v2 达标后 A 退役为质检器。

## 6. 执行分期(0830 定,综合外部 code review;每期单变量)
- 背景:train_dual/spatial5 里 arm_boost/ee_boost/fk_loss/tail_alpha/var_floor/visible_boost 六开关
  代码俱在、生产全 0;现役位置损失为无加权 L2(上肢梯度份额 ~11%)。已有五个加权机制,
  新增前必须先消融归因(七机制抢梯度警告,采纳)。
- P0 只开开关(3.67M 小规模 ×3 臂): a) var_floor(幅度压缩已诊断:0813 punch 渲染) b) fk_loss c) both。
  判据:幅度比 / 上肢误差 / **腿角(预注册,不许退化)** / 方言逐维格距。
- P1 方差归一化(σ 数据统计 + ε=目标精度² 地板)替换 arm/ee_boost 关键词表;可叠杠杆臂乘子。
  腿部退化则第一替补 = Kendall 学习σ(带上限)。
- P1.5 slip 副批(**lloyd 决议:slip 不去 Equator**):主批单帧不动,副批(1/4 batch)取片段内相邻行对,
  两帧各解码,仅副批算 slip。依据:精修器A 实测支撑相漂移 21-44cm/s 源于相邻帧解码不一致,
  码本身无病,Equator 层触及不到 decoder。验收:支撑相漂移 <0.15 m/s。推理保持严格单帧。
- P2 接触通道 [B,J,9]→[B,J,13](rot6d+pos+c+n),破坏性,独立分支;法向平地写死(0,0,1)通道预留,力不进码。
  前置:预训练全语料过接触标注器(人体侧 FK + 低且慢+滞回;纯CPU离线)。

## 7. 接触约束的正确形式(0831 lloyd 三连纠正后重写;原"法向对齐"版本作废)

**纠正一:不许写法向对齐。** 跑步只脚尖点地也能跑,滚转俯仰全自由 —— `‖Rᵀn − n_sole‖` 是过约束。
正确形式只钉接触点,不提朝向:
    L = Σ_b relu(−d_b)²           全身所有碰撞体不许穿模(不等式,物理先验)
      + Σ_{b∈接触} |d_b|          该碰的必须碰到
      + Σ_{b∈接触} ‖v_切向(p_b)‖  碰着的点不许滑
自由度自动对:脚尖 1 点→剩 3 个旋转自由度;外沿 2 点(线)→剩 1;全掌 ≥3 点→0。
**损失不需要知道是哪种接触,钉住实际接触点即可,该锁的自己锁、该松的自己松。**

**纠正二:接触是全身的,不是末端的。** 躺地时手/髋/膝/躯干都在接触 => 通道按 body link 设(约 30 个碰撞体),
每 link: `接触位(1) | 接触点在该 link 自身坐标系的位置(3) | gap(1)`。
**"接触点在自身坐标系"是关键**:它区分脚尖/脚跟/脚掌,正是决定锁几个自由度的信息;原设计只存法向恰恰丢了它。
机械现成:精修器 A 已用 MuJoCo `contact.dist` 拿穿透深度,同一查询直接吐接触点。

**纠正三:约束作用于全身关节,不止末端。** 髋着地+脚着地 = 闭链,中间整条腿被锁定;
可微 FK 让梯度自动沿运动链回流(踝→膝→髋→腰)。作用域是"接触体到根的整条链",不是那一个关节。

**纠正四(lloyd:"接触本身其实就是关节旋转") —— 立项理由由此重新定性:**
接触状态是姿态的确定性函数,所以接触码在**信息上冗余**。它的真正价值是**重新加权**:
现役旋转损失是逐关节测地角,对杠杆臂盲目 —— 踝差 5° 在踩地时整个身体倾斜、在腾空时什么也不发生,却扣同样的分。
接触损失经 FK **把旋转误差按当前接触构型下的物理后果加权**。
=> **接触码不是第九种加权:前八种是在同一把盲尺上换权重,它是换一把知道物理后果的尺。**
token 本身(区别于损失)的价值:LLM 可读、生成时可控("这一步腾空")、将来触觉接口 —— 冗余但有用。

## 8. 源数据本身就穿模/标错 —— 四条对策
实测污染:原生 retarget 自穿 2.5-4.3cm,接地标定 ±3cm(Adam 走路悬空 3.3cm),标注器跑/跳漏检 39%/59%。
1. **用不等式不用回归**:`relu(-gap)` 是物理先验不是数据拟合 => 训出的模型可以比训练数据更干净。这是接触损失唯一能超越数据质量的机制。
2. **速度免标定,拿它自举地面**:脚水平速度与地面位置无关 => 先只用"慢"找候选支撑帧 → 从这些帧稳健拟合地面 → 再用高度门确认。地面标定从数据自己长出来。(今天压力测试里"舞蹈 0.22s 摔倒"正是全片段 p10 接地规则的锅,此条直接治它。)
3. **置信掩码**:标注器已偏保守(漏报优于误报),模糊帧不给接触监督,宁可少教不可教错。
4. **分级信任**:触觉实测 > 仿真物理 > 几何标注器 > 无监督,损失权重按层级给,数据管线自带质量标记。

## 9. 立项证据(0831 三具身确认)
GR3/Adam/X2 同窗解码穿地 p95 = 10.4/14.2/10.7cm(爬行),骨架/限位/身高比差异巨大而穿地只差 1.4 倍;
同台 GR3 原生 retarget 仅 2.5cm(差 5 倍);解码臂关节饱和率 0.2-5.3% **低于**原生的 3.0-15.6%(限位不背锅);
**走路对照臂三台解码穿地 1.3/3.0/2.1cm 与原生同量级,地面动作是它的 4-8 倍**(管线地板排除)。
膝/髋屈曲跟得住人体(差 5-10°)=> **姿势没崩,崩的是身体与地面的关系**。判决:通病(表征),非具身墙。
