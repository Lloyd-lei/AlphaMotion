## B. 数据流

```
人的动作(SMPL local6d)
  → Greenwich 编码 ────────────→ 码 [每帧 256 槽 × 20 维]
                                    ├ 128 槽 位置流 ← 对渲染零影响(见 D1)
                                    └ 128 槽 旋转流 ← 渲染只用这半
  → Stage A 压成 32 个 token
  → Stage B 预测 token (生成发生在这里)
  → Stage A 解回码 → Greenwich 解码 → 任意机器人(16 具身,3 个留出)
  → 渲染:只取旋转,过 FK 得位置(v5_common.fk_pos 是唯一的位置尺子)

文本 → 冻结 Qwen → 整个词序列 [L,1024] → 线性投影 → 文本记忆
     → Stage B 每层交叉注意力   ← B5,似然打平/组合部分成立(D5)
文本 FSQ codec 现在只用于检索与索引,已退出条件化通路
```

## D. 已知缺陷与状态

### D1 一半码本对渲染零影响 —— 已确诊,未处理
位置码清零/打乱,渲染出的动作**逐比特不变**(FK 位置差 0.00000 cm;对照:旋转码
清零差 12.88 cm)。解码器两条流不交叉,`hrot` 从未见过位置码,而渲染只用旋转。
波及:Greenwich 存储、Equator token 宽度、Stage B 的预测目标,各有一半在空转。
**但位置头在训练时有用**(rot_only 消融的幅度更差),lloyd 定案:留头、但不该
独占槽位。未测的第三方案 = 位置头接在旋转码上。
判决: `verdicts/DEAD_HALF_0812.txt`, `FK_DUEL_0813.txt`

### D2 重编码往返崩溃 —— 已修,待加冕
`encode(decode(z))` 保真度仅 11%(随机=0)。血案分离:编码器无罪(49~54%),
**解码器是唯一凶手**。修法两条都验过:
- 全量重训带 reenc: 11%→61%,代价零样本 G1 +12%
- **只训解码器 + 冻结编码器/码格 (`PT_c1dec_reenc_0812`): 11%→61%,
  码逐比特不变(零下游连锁),翻译精度几乎不变** ← 推荐采用,**尚未加冕**
判决: `verdicts/REENC_ABLATION_0812.txt`, `REENC_CROSSOVER_0812.txt`

### D3 A3/B3 token 契约分叉 —— 已焊死
`bridge_a.encode()` 用 time-local 掩码,`bridge_b.tokens_of()` 曾不用。两套 token
**只有 0.15% 重合**,B3 吃错流罚 +15.2 nats。`tokens_of` 现有显式 `masked` 参数
+ 文档 + 写进 config,**默认保持旧行为**以复现现有检查点。
影响面:B 家族内部自洽(所有 B-vs-B 比较有效);**文本层曾对齐到错误空间**(D5)。
判决: `verdicts/CONTRACT_AUDIT_0812.txt`, `VERSION_AUDIT_0812.txt`

### D4 自主流无吸引子 —— 监督路线关闭
去掉终点让模型自主前进:B3 冻结(回归映射斜率 −0.09)、B6 漂移(+0.90)、
B7 漂移减半(+0.38)、B8 整周期窗口被否(+0.50);语料步态是 −0.70。四种教法
都不管用,因为**逐 token 似然里没有轨迹级回归项**。E17 RL 是指定下一步,
奖励 = −(斜率+0.70)² − w·幅度缺口, init=B7。
**必须在修好的解码器上跑**(否则是在被污染的状态转移上优化)。
lloyd 的重构:没有目标就该站着不动("发呆"),所以缺的是**意图**不是动力学。
判决: `verdicts/PHASE_SPACE_B6_verdict_0811.txt`, `ROLLOUT_B7/B8_verdict`

### D5 文本条件化 —— B5 交叉注意力已上,似然打平/组合部分成立
B4 五轮(v1~v5)都是"8 个输入条件槽 + FSQ 文本码",视觉不可辨。0814 换代 **B5**
(`BRIDGE_B5_xattn_0814`):Qwen **整个 BPE 词序列**(不池化)→ 线性投影(**不做 FSQ**)
→ **每层交叉注意力**;条件槽 [起点,终点,n] 不变;加**组合损失**(生成过检索器要被
认出);零初始化使第 0 步与 B3 **逐比特相同**。
- **似然口径打平**:同一批 5760 窗口配对评估,B4 +0.0747 / B5 +0.0818 nats,
  置信区间大幅重叠,B5 帮到的窗口反而更少(52.6% vs 55.4%)。训练日志里的 0.122
  是 8 批噪声。
- **组合口径部分成立**:起点=终点=站姿、24 种子、CFG w=8,用**运动学签名**判
  (FK 直接量,训练无法作弊),基线取**中性 prompt @同等引导强度**。
  `run+clap`(语料零共现)组合列在**双签名上都超过两个亲本**(脚 d+2.40 / 手 d+5.31,
  双手 40.0→28.8cm);`walk+wave` 未通过(下肢反向,疑似卡 D6 无平移)。
  w≤4 时组合列落在噪声内 → **文本强度仍不足,不算已解决**。
- w=8 不是畸变:jerk 0.249 比真实语料 0.725 还平滑,限位命中 8.1% vs 语料 6.1%。
- **检索判官与运动学判官打架**,已记录:检索器在语料上训,零共现组合对它就是分布外,
  它没能力认;`gen_R5` 本身是训练损失的一部分,两者都只能当参考。
- 前提修正:walk+wave 在语料里**有 46 条共现**(0.18%),是低资源不是零样本。
判决: `verdicts/B5_XATTN_COMPOSITION_0814.txt`, `B4_TEXT_COND_verdict_0811.txt`

### D6 表征缺世界平移与地面 —— 未处理
姿势是根相对的(`gp / reach`),所以**世界平移和离地高度都不在表征里**。
`root_world.pt` 有 473 万帧真值(6 具身, Y-up, cm)但**训练从未使用**。
lloyd 定案:表征必须位置无关,平移应从跨步积分——已验证可行(接触积分重建
根轨迹,净位移相关 +0.988,6 秒漂移 13cm)。**平移属于 Equator 不属于 Greenwich**
(Greenwich 逐帧,结构上算不出平移)。
接触标签可算但需四步谨慎版(脚底偏移/每 clip 估地板/速度门控/审 6% 穿地帧)。
判决: `verdicts/GROUND_FRAME_CHECK_0812.txt`

### D7 手臂尾巴 = 标签失真,非模型问题 —— 四次排除后定案
| 嫌疑人 | 判决 |
|---|---|
| 解码器容量 | 否(两轮后训 <1%) |
| 损失接线(FK 损失) | 否(~2.5%) |
| 码本预算(128 vs 256) | 否(1~4%) |
| 关节限位截断 | 否(难族/易族命中率 4.88% vs 4.98%) |
| 族稀疏 | 部分支持(corr −0.684)但被混淆,run 是反例 |

直接量标签(全程无模型):**重定向把手方向改了 43.4°、脚 26.4°,手臂失真是腿的
1.64 倍**,四个机器人无一例外。且**踝在各身体上高度一致(差 17%),腕差 2.6 倍**,
**右腕在每个身体上都比左腕差**——后两条几何解释不了。
读出探针佐证天花板在标签:码→人腕 p95 12cm,码→配对机器人腕 p95 30cm。
判决: `verdicts/RETARGET_LIMB_DISTORTION_0813.txt`, `DECODER_PT_verdict_0811.txt`

## E. 已确立的能力(有判决书背书)

- 跨具身翻译:16 具身共享一套码,3 个留出零样本
- 桥接:P(中间 | 起点, 终点, n),端点直通,逐个精确采样
- **自监督变速**:同一串 token 渲染成任意时长(300 帧武术 / 240 帧舞蹈 0.5×/1×/2×)
- **稀疏 pin**:约束遵守单调(k=0/8/16 → 0.209/0.344/0.430)
- **扰动重规划**:被拖过整段外来动作后到达只贵 1.7%,两个接缝的最大单帧步
  (1.92/1.65cm)比干净动作自身的最差帧(4.08cm)还小
- **n 可推断**:让先验自选节奏比给定 n 更准更顺(2.31 vs 2.41cm,抖动 0.73 vs 0.89)
- **零真值评估体系**:相图回归映射、姿势自由度/恢复视野、半群自洽、求解器证书
  (R² 0.235,80% 区间实际覆盖 83%)、幅度比、一致性差距

## F. 评估纪律(踩过的坑)

1. **位置一律走 FK**(`v5_common.fk_pos`)。原始位置流是"橡皮筋骨头",
   `rot_only` 模型的 `pos_cm` 列直接作废。
2. **同骨架无观测解码禁入判决**(vis_residual OOD)。
3. **跨具身误差要同时报归一化单位**,否则最大的身体永远最难看。
4. **新指标先打印中间量核对**。0813 三次撤回全是这一条没做:单 clip 当全局、
   码算错(两层投影)、关节配对错(人体被解析成"肘-腕-肩")。
5. **两个检查互相矛盾 = 有 bug**,要立刻追,不能先信数字。
6. **对照臂三件套**:管线地板、随机方向、同尺重测。
7. 均值会掩盖尾部;幅度塌缩在均值上看不见,难例上才现形。
