# 三具身地面动作对照 (GR3 / Adam / X2) —— 0831

一句话: **地面动作的失败是通病, 不是某台机器人的关节墙。** 三台机器人、同一段人体、
同一个生产 Greenwich, 穿地深度 10-20cm 彼此差不超过 1.6 倍; 而同一台机器人上原生
retarget 只穿 2.5-4.2cm。腿部关节几乎没到限位。→ 接触标签这条路有理。

### 两个约定, 都实测定的, 不是拍的

**根朝向 = 解码骨盆。** 人体 rest 骨盆系和机器人 rest 骨盆系差一个近似常量旋转
(rpy ≈ 90°,0,90°; 残差 2-9°)。人体根旋转直接套到机器人上是 **123°** 的错, 机器人
会整个埋进地里 (第一版实测穿地 40-53cm)。解码骨盆本来就在机器人自己的系里。
解码骨盆 vs 原生骨盆的偏差: **7.3-13.7°** (四窗两机器人)。

**根位置 = 人体根轨迹 × 站立高度比。** 站立高度 = qpos0 下骨盆原点到最低脚底顶点。
x2_family 用整身 reach 比, 实测把 GR3 压低 3cm、Adam 压低 12cm (Adam 腿短但脚厚,
reach 比 0.689 / 腿长比 0.924 / 站立比 0.971)。**不做**"把最低脚顶到地面"的事后平移
—— 那会把穿地深度定义成 0。

### 对照臂 (关键)

LAFAN 是配对缓存, GR3/Adam 有 xwbc 原生 retarget, 所以每台机器人上都能问一句

   —— 它影响躯干姿态, 不解释地面动作的脚。

## 判决

**通病 (码本/表征), 不是具身墙。** 四条证据:

1. **横向一致**: 同一窗三台机器人的穿地 p95 = 10.4 / 14.2 / 10.7 (爬行),
   10.8 / 17.2 / 9.7 (摔倒), 2.4 / 5.9 / 3.7 (aiming)。最差的 Adam 只比最好的
   X2 差 1.4-1.6 倍。三台的骨架、限位、脚型、身高比 (0.971/0.971/0.706) 差别很大,
   失败幅度却几乎一样。具身墙不会这么整齐。
2. **纵向同机器人对照**: 同一台 GR3、同一副网格、同一把尺子, 原生 retarget 穿地
   2.5 / 4.2 / 0.0cm, 解码 13.0 / 12.1 / 3.5cm —— **差 3-5 倍**。这台机器人做得到, 是
   解码没把它放到地上。Adam 同结论 (3.0 vs 16.6, 3.6 vs 20.5, 2.9 vs 6.8)。
3. **限位不背锅**: 解码臂的关节饱和率比原生**更低** (0.2-5.3% vs 3.0-15.6%), 顶墙的
   是手肘和腰, 腿链最高 12%。解码根本没被限位卡住。
4. **管线地板已排除**: 走路对照窗三台解码穿地 1.3 / 3.0 / 2.1cm, 和原生同量级。
   地面动作的 10-20cm 是它的 4-8 倍, 远超测量噪声。

另一条同向的证据: 支撑脚滑移。解码 26-84 cm/s, 原生 17-42 cm/s, 走路窗解码只有
19-29 cm/s。脚一旦落到地面附近就在地上蹭 —— 码里没有"这只脚此刻钉住"这件事。

**所以接触标签是对的杠杆**: 失败集中在"身体与地面的关系"这一个自由度上, 而这个自由度
在当前的表征里根本没有被编码 (旋转流 + 根轨迹, 没有接触项)。姿势层 (屈曲角) 已经学到
了, 限位也还有余量, 换机器人换不掉这个问题。

三条附带的坑, 写下来免得下次踩:

- 人体根朝向**不能**直接透传给机器人 (rest 骨盆系差 ≈90°,0,90°, 实测 123° 误差)。
- 根高度**不能**按整身 reach 比缩放 (Adam 会被压低 12cm)。按站立高度比 (qpos0 骨盆到
  脚底) 缩, 三台走路窗残差都 ≤3cm。
- 原生 retarget 自己也有 ±3cm 的地面标定 (Adam 走路时整个人悬空 3.3cm), 所以
  <3cm 的穿地差异不要解读。
