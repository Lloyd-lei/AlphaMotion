# E-BFM:离散运动学表征(Greenwich)上的 BFM 式动力学学习 —— 完整计算蓝图(0829)

前提设定:Greenwich 全程冻结;token 序列保持序列(z 流),不压缩;策略网络 transformer(宪法)。
分两期:v0 = PPO 复用现有管线,一晚出信号;v1 = 忠实 BFM(off-policy + F),本文主体。

## 0. 空间与符号
- s_t:X2 本体感受(joint pos/vel 62 + base lin/ang vel 6 + 上步动作 31 + 重力/朝向) ≈ 108 维;critic 另加特权项。
- z:意图向量,512 维 = Greenwich pooled proj_out(量化前连续特征),L2 归一化 ×√512 投球面
  (仅归一化条件输入,不动格子拓扑)。**大脑接口仍是离散码**:码 → 冻结 proj_out → 乐句平均 → z。
- 乐句编码 phrase(x, t) = mean(feat[t+5 .. t+25])(0.1-0.5s 窗,V1 判决:±0.3s 邻域可用,逐帧不可用)。
- B̂(s):机器人状态 → 同一 z 空间。实现 = z_curr 机器:在线 Greenwich 编码 X2 姿态(世界系,V1 定的约定),
  v1 用蒸馏头替代(2 层 MLP 拟合,验收 R²>0.98,400 倍便宜,柱二 S2 的既有设计)。

## 1. 网络(全部新训,MLP 除 actor 外)
| 网络 | 结构 | 作用 |
|---|---|---|
| π(a|s,z) | 现有 TokenTransformer:[ACT]+z token(512→d)+proprio token,d256×4层;tanh 均值,σ=0.05 固定 | 演员 |
| F(s,a,z) | MLP 1024-1024-512,**双份并联集成**(取 min 防过估) | 可达性(动力学表征本体) |
| D(s,z) | MLP 1024×2,输入 concat(s,z) | 般配裁判(吸收方言) |
| Q_disc / Q_aux | MLP 512×2 各一 | 风格/惩罚的 TD 经纪人 |

## 2. 采样循环(每个 sim 步,4096→v1 可降 1024 env)
1. 物理步进 → s_t。
2. **z 指派**(逐 env,三流混合):
   - 50% 专家流:池窗/Equator 生成窗的码序列,z_t = phrase(ref, t+15);**每 25 步(0.5s)滑动一次** —— z 流,时序在流里;
   - 30% 自由流:z 固定 2s 后重抽(60/20/20 = 专家乐句/随机数据态乐句/球面均匀);
   - 20% 躺地出生流(fallen_init):z = 最近站立乐句 —— 起身从这里涌现。
3. actor 前向 → a_t → X2_ACTION_SCALE → PD。
4. B̂(s_{t+1}) 前向(蒸馏头,微秒级)。
5. 写回放缓冲(容量 5M):(s, a, s', z, 原始惩罚分量, done)。
6. **终止:无**(只 10s 超时 + 根高 z<0.2 的防炸底线);RSI 扰动开(BM 全套 ±5cm/±0.5m/s/±0.1rad)。

## 3. 更新循环(每 64 env 转移一次,batch 1024,全 bf16)
A. 抽 batch;抽专家配对 batch:**xwbc 18 具身配对缓存**给 (机器人状态, 人体乐句 z) 真配对。
B. **判别器**:L = BCE(真对 vs 策略对,策略按未标注 softplus)+ 10×WGAN-GP;专家 z detach。
C. **F(向量 TD,USF 形式)**:
   y = B̂(s') + γ·F̄(s', π(s',z), z)   (F̄ = EMA 目标网,集成取 min 于 F·z 标量)
   L_F = ‖F(s,a,z) − y‖²
   —— 这就是"动力学表征"的全部训练:F 把"从这做什么能路过哪些码域"学进权重。
D. **Q_disc**:r_disc = logD/(1−D)(s',z),标准 TD;**Q_aux**:r_aux = −2·滑步 −4·踝滚 −10·超限 −0.1·动作率(BFM 权重),标准 TD。
E. **actor**:max E[ F(s,π,z)·z + 0.05·|F·z|·Q_disc + 0.02·|F·z|·Q_aux ] —— 100:5:2,惩罚自动配平。
F. 目标网 EMA(τ=0.005);lr:π/F 3e-4,D 1e-5;γ=0.98。

## 4. Equator 的位置
专家流的出题机:homecoming/rainbow/retime 码序列直接当 z 流课程;后续按考试失败率做 EMD 式加权。

## 5. 判官(不变 + 新增)
- 严判考试、固定 8 窗视频、foot_audit 照旧(纪律不动);
- 新增 abstention 度量:min_z∈已达集 ‖B̂(s)−z‖,超阈直接报"没学过" —— 宪法条款的原生实现。

## 6. v0 捷径(先跑,验前提,一晚)
PPO 原管线不动,只换奖励:
  r = 1.0·⟨B̂(s_{t+1}), z_t⟩ 进度分 + 0.05·D 般配分 + 原惩罚(轻量)
z 流照第 2 节;零终止 + fallen_init 0.2。缺 F 的长程传播(PPO 的 GAE 只有 λ 视野),
预期能起步、可能中途平台;平台即 v1 动工的信号。

## 7. 风险清单(诚实)
- B̂ 冻结 → 无 FB 最优性保证,是"冻结特征的 USF",理论弱一档、工程强一档;
- 码只能粗定位(帧准 4%)→ 乐句级意图是下限也是设计;精追踪指标预期让位,靠 D 补风格;
- off-policy(v1)是我们没跑过的栈(SAC 曾 2/9 惨败 PPO)——但那次是 tracking 合同制任务,达成性任务是 off-policy 的主场,须重测不能沿用旧判决;
- 判别器塌缩风险 → WGAN-GP + 未标注式损失照抄 BFM,不自创。
