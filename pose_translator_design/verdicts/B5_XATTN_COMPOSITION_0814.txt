B5 交叉注意力文本 wrapper —— 判决 (0814)
===============================================================================
运行: BRIDGE_B5_xattn_0814 (24k 步, 14.72M 参数, 从 BRIDGE_B3_prod_0810 热启动)
对照: BRIDGE_B4v5_fixed_0812 (旧 wrapper, 8 个输入条件槽 + FSQ 文本码)
Greenwich / Equator A3 / B3 全程只读,未改动任何既有权重。

lloyd 0814 的要求
-------------------------------------------------------------------------------
"没有必要为了 fsq 而 fsq,大语言的 bpe 词表已经很成熟...我现在需要的是 prompt 的
动作组合能力,walk 和 wave hand 在数据集里面都没有出现过,但是 prompt 输入可以把
边走边挥手给组合出来。"

四项改动(全部落地)
-------------------------------------------------------------------------------
1. prep_text_seq.py  2.6 万条 caption 重过冻结 Qwen,保留【整个 BPE 词序列】
   [32,1024] fp16 + 长度,不再池化成 1 个向量。中位 13 个词,缓存 1.70 GB。
2. bridge_b5.py      每层 = 自注意力 -> 【交叉注意力查文本记忆】-> 前馈。
   条件槽 [起点,终点,n] 不变。cross_attn.out_proj 零初始化。
3. 文本侧【不做 FSQ】,线性投影 + LayerNorm,跟 B 一起训(不冻结)。
   离散文本码只留给检索/索引,退出条件化通路。
4. 组合损失: 预测分布软嵌入进冻结的 TEXT_ALIGN_v3 检索器,
   "生成的东西必须还能被 prompt 认出来" -> 可导。权重 0.1。

热启动正确性: 零初始化使 B5 在第 0 步与 B3 【逐比特相同】(max|Δlogits| = 0.000e+00)。

结论 1  似然层面:交叉注意力【没有】带来实质提升
-------------------------------------------------------------------------------
text_gain_eval.py,两臂在【同一批 5760 个】留出窗口上配对评估(全掩码,扣终点):

  B4v5 (旧)   +0.0747 nats   95%CI [+0.0649, +0.0847]   帮到 55.4% 的窗口
  B5   (新)   +0.0818 nats   95%CI [+0.0718, +0.0924]   帮到 52.6% 的窗口
  差   +0.0071 nats (+9.5%),置信区间大幅重叠;B5 帮到的窗口反而更少。

训练日志里出现过 0.122,那是 8 批 x 48 的噪声,不能采信。
=> 在"文本能多大程度上预测留出片段"这个口径上,两种 wrapper 打平。

结论 2  组合层面:zero-shot 组合出现了,但只在一组、且必须靠引导放大
-------------------------------------------------------------------------------
协议: 起点 == 终点 == 同一个站姿(端点不含动作信息),90 帧内部全由文本决定;
每列同起点同种子,24 个种子;无分类器引导 w(两臂都训过文本 dropout)。
判据是【运动学签名】—— 从 FK 直接量,与任何学到的嵌入无关,训练无法作弊:
  foot_osc 双踝间距的时间标准差    hand_osc 双腕间距的时间标准差
  hand_min 双腕最近距离            arm_lift 腕相对头顶的最高高度
基线用【中性 prompt "a person" @同等引导强度】,而不是无引导的空文本 ——
否则高 w 下的整体放大会被误读成语义效果。

A. run + clap  (语料共现 = 0 次;亲本各 1339 / 257 条)   -> 通过
   相对中性基线的效应量 d:
                 foot_osc   hand_osc   hand_min   arm_lift
      run 亲本      +1.71      +1.88      -1.53      +2.22
      clap 亲本     +0.54      +1.62      -1.62      +2.72
      组合         +2.40      +5.31      -6.12      +5.81
   组合列在【两个签名上都超过各自的亲本】。原始值:双手间距 40.0 -> 28.8 cm,
   抬手高度提高 18 cm,脚部振荡 8.9 -> 11.6 cm。
   只在 w=8 出现;w<=4 时组合列落在噪声内。

B. walk + wave  (lloyd 举的例子;语料共现 46 次)          -> 未通过
   三列的 foot_osc 全部【低于】基线(walk 亲本 d = -0.57,组合 d = -0.91)。
   上半身有反应(组合 arm_lift d = +2.18, hand_min d = +1.62),下半身没有。
   最可能的原因是 D6: 表征无世界平移,"向前走"只能表现为原地迈步,
   而迈步在双踝间距上的信号本来就弱。

结论 3  CFG=8 不是把动作搞畸形搞出来的假象
-------------------------------------------------------------------------------
cfg_plausibility.py,与真实重定向语料对照:
                     jerk      限位命中(2% 内)
   真实语料         0.7252         6.1%
   w=1              0.1513         7.9%
   w=4              0.1992         8.2%
   w=8              0.2486         8.1%
   w=12             0.2983         7.4%
w=8 的输出比真实动作【还平滑】,也没有撞关节限位。组合信号不是畸变。

两个判官打架(按纪律必须记录)
-------------------------------------------------------------------------------
检索判官(相似度矩阵)在两组上都判【未通过】: 它认为 run+clap 的组合结果像 run
(0.747) 而不像 clap (0.177)。运动学判官判通过。
解释: 检索器是在语料上训的,而 run+clap 在语料里零共现 —— 真正的新组合对它
本身就是分布外,它没有能力认。这与结论自洽,但【是检索判官的局限,不能反过来
当作组合成立的证据】。gen_R5 同理:它直接就是训练损失的一部分,只能当参考。

前提修正(写给后来人)
-------------------------------------------------------------------------------
lloyd 说 walk 和 wave hand 数据集里都没出现过 —— 实际有 46 条 caption 同时含两者
("person is waving and walking"),占 0.18%。属于极低资源,不是零样本。
全量 25,936 条 caption 审计后,真正零共现且亲本充足的下肢x上肢组合有:
   backward+clap, crouch+drink, jump+drink/phone/scratch_head,
   kick+clap/cross_arms/drink/phone/point/scratch_head, run+clap ...
本判决用 run+clap 作零样本组,walk+wave 作低资源组,两组都报。
caption 本身信息量没问题: 23,507 条不重复(95% 唯一),词汇 7,362。

下一步(按我的排序)
-------------------------------------------------------------------------------
1. 组合能力只在 w=8 出现,说明文本信号强度仍不足 —— 这是 wrapper 的下一个目标,
   而不是"已经解决"。方向: 提高 captioned 批次占比、拉长训练、或把组合损失权重
   从 0.1 上调并加正则防止走捷径。
2. walk+wave 的失败大概率卡在 D6(无世界平移)。平移作为 Equator 新输出通道
   (root_world.pt 现成)会直接冲击这一条,应提前。
3. 组合的另外 14%: 之前的原子性测试里,合成动作有 14% 的(位置,码)对在语料中
   "该位置没见过"。若加强文本后仍组合不出,这 14% 是下一个要查的地方。
4. 检索判官需要一个语料外的替代品,否则组合类实验永远缺一个独立语义判官。
