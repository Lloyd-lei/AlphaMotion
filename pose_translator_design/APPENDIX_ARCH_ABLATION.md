日期:2026-08-03 · 状态:草案,供 lloyd 审阅 · 前置文档:`LOCKED_PLAN.md`(锁定 v2)、`R3_REVIEW/REPORT.md`

## A. 设计原则(先立法,后设计)

1. **离散是接口,连续是计算。** FSQ 码 = 存储格式、跨具身对齐的度量对象、未来大脑(VLA)的词表;生成计算走取整前的连续 latent,保证 SE3 梯度引导通路不断。FSQ 的量化 = 有界空间取整,与 diffusion 天然兼容(MAR 路线);这是当初选 FSQ 而非 VQ 的追加红利。
2. **codebook 与 diffusion 分层不冲突**:codebook 管表示,diffusion 管分布建模。唯一的耦合点是推理时梯度,由原则 1 解决。
3. **约束穿透全栈**:SE3 稀疏约束三层机制(条件注意力→扩散引导→IK 投影),精度最终由最硬的一层保证,不指望网络收敛。
4. **WBC 是评委不是下游**:可跟踪率进常规评估,运动学指标只是代理。
5. **bitter lesson 延续**:除已锁定的 twist 单独处理外,零手工结构;新结构必须先在消融中击败无结构基线才准进主线。

## B. 整体架构(三段式,B 方案)

```
        ┌──────────────────────────────────────────────────────┐
        │ ① 拓扑无关 tokenizer(预训练后冻结)                      │
        │  per-joint token(SE3-6D+相对根位置+骨长+hop图偏置        │
        │   +SigLIP关节名+rest-pose) → 图注意力编码器              │
        │   → K个查询token池化 → 连续latent z ∈ [-1,1]^d          │
        │   → FSQ取整得码(存储/度量用)                             │
        │  训练目标:全身重建 + 掩码关节重建(MAE式) + InfoNCE跨具身   │
        │  root 显式通道,不进latent                               │
        ├──────────────────────────────────────────────────────┤
        │ ② 时序主干(复用ARDY):因果transformer + 分块latent        │
        │   diffusion头,在连续z上自回归出下一块                     │
        │  条件:文本prompt ⊕ prefix(当前状态) ⊕ 约束token集         │
        │       (关节描述向量⊕时间编码⊕SE3⊕掩码⊕参考系标志,          │
        │        交叉注意力注入,训练时随机稀疏丢弃+CFG)              │
        │  推理:每个去噪步可选梯度引导(解码→FK→约束残差→修latent)     │
        │  主干不吃目标骨架 —— 具身无关性由①的码空间保证              │
        ├──────────────────────────────────────────────────────┤
        │ ③ 拓扑无关解码器:z + 目标骨架(图/rest-pose/关节名)         │
        │   → 各关节SE3 → FK                                     │
        │  末端硬投影(IK,零空间摊误差)兜底约束精度                    │
        │  输出 → 每台机器人的 WBC 跟踪策略(BeyondMimic配方)          │
        └──────────────────────────────────────────────────────┘
```

三个非显然的设计点:
- **主干具身无关**:②只看码/latent,不看目标骨架。这是"一个大脑所有身体"的前提,也是 E5 要验证的最大假设。
- **约束寻址 = 关节描述向量**:控制信号说"手腕这个语义"而不是"13号关节",跨具身零改动。
- **A(全离散GPT)与C(全diffusion)保留为对照组**,分别度量"离散的税"和"码本的税",不是主线。

## D. 消融矩阵(逐层锁定,不撒网)

### 第 0 层:表示层收尾(部分已在 R3 完成)

| 编号 | 实验 | 变体 | 主指标 | 锁定判据 | 杀死判据 |
|---|---|---|---|---|---|
| E0a | FSQ 比特预算 | token数K × 每token比特,率失真扫描 | 重建 + **似然** + **部分观测稳定性** | 三指标拐点重合处 | — |
| E0b | 掩码预训练 on/off | 掩码族{单末端/只留根/随机关节/随机时间段} | 部分观测稳定性、重建不退化 | 稳定性显著提升且重建<10%退化 | 重建退化>10% → 降掩码率 |
| E0c | 双码本(位置/旋转分路) vs 单码本 | R3 用双,验证是否必要 | 重建、似然 | 简单者优先(差距<5%取单) | — |

### 第 1 层:生成层三选一(命运实验,与 E5 并列最优先)

| 编号 | 实验 | 变体 | 主指标 | 决策规则 |
|---|---|---|---|---|
| E1 | 时序生成类别 | A: 离散AR-LM(GPT式)<br>B: 分块latent diffusion(ARDY式)<br>C: 全序列diffusion(离线上界参照,不参与实时评比) | 生成质量、**约束满足阶梯**、延迟 | 预注册预测:B 在约束满足上碾压 A(A 无引导通路)。若 A 生成质量+延迟大幅优于 B 且约束差距可被 IK 层补 → 重新开会;否则锁 B |
| E2 | 空间token粒度 | 每帧K∈{1,2,4}个latent × 时间窗∈{1,4}帧 | 率失真、似然、约束时间分辨率 | 时间窗>1 会粗化约束时序,除非似然收益>20% 否则锁窗=1 |

### 第 2 层:约束注入(锁定生成层后)

| 编号 | 实验 | 变体 | 主指标 | 决策规则 |
|---|---|---|---|---|
| E3 | 注入机制 | 条件token交叉注意力 / inpainting式掩码 / 两者叠加 | 约束满足 + 补全自然度 | 单机制够则不叠加 |
| E4 | 精度阶梯 | 引导步数∈{0,2,5,10} × IK投影on/off | 约束误差-延迟曲线 | 找实时预算内甜点;报告每层贡献 |

### 第 3 层:跨具身 scaling(与 E1 并行启动,数据管线独立)

| 编号 | 实验 | 变体 | 主指标 | 决策规则 |
|---|---|---|---|---|
| E5 | 拓扑数量曲线 | 训练拓扑 2→5→10→17(GMR全家桶),固定留一评估 | 留一本体零样本重建/翻译 | 曲线下行 → 锁"无结构+堆拓扑",写scaling recipe;曲线平 → bitter lesson假设证伪,回头设计最小结构(part-token为首选) |
| E6 | 泄漏探针纵向 | 随 E5 每个拓扑数报一次 | 探针准确率 | 应随拓扑数下降;不降则加具身对抗损失 |

### 第 3.5 层:码本-具身多样性 scaling law(E9,lloyd 提议 2026-08-03)

| 编号 | 实验 | 变体 | 主指标 | 决策规则 |
|---|---|---|---|---|
| E9 | 比特预算 × 具身数量 二维扫描 | bits∈{~500, ~1000, ~2000} × N∈{2,4,8,13}(GMR 生产数据就位后) | 翻译误差、泄漏、AR似然,画二维热图 | 回答:泄漏最优比特是否随 N 增长?"高比特伤不变性"效应是否随 N 减弱(多余容量从记身体转向跨身体共享)? |

预注册预测(E9):N 增大时,固定比特下泄漏下降;高比特的泄漏惩罚随 N 减弱;质量最优比特随 N 缓慢右移。
背景:tokenizer 的"码本大小 vs 数据规模"在图像界有零星研究(FSQ 原文、MAGVIT-v2 词表实验),但**比特预算 × 本体多样性 × 表示不变性**这个三元组没有先例——不变性轴是本项目特有的。若曲面形状清晰,可单独成文。

## E. 预注册预测(先写答案再对卷,防事后合理化)

1. E1:A(全离散)约束满足误差 ≥ 3× B;B 生成质量与 A 相当或更好。
2. E0b:掩码预训练使部分观测码稳定性提升 >50%,重建退化 <5%。
3. E5:留一误差随拓扑数近似幂律下降;10 本体时 <5cm(当前 2 本体 12cm)。
4. E4:引导 5 步 + IK 投影可把末端误差压到 <5mm,总延迟仍在 40ms/帧内。
5. E7:初版可跟踪率 60–80%;不可跟踪样本集中在高动态段与接触切换段。

## F. 资源与纪律

- 单卡 Blackwell 96GB;kimodo 常驻占 ~15GB;E0/E1 量级 ≤20M 参数、万步级,天级周转。
- checkpoint/cache 一律 `/var/tmp/alphamotion/`,严禁写 /home(97% 满)。
- 数据:BONES-SEED 14.2万条配对(601GB);E5 需 GMR 批量重定向,先估磁盘再跑。
- 每个 run 命名 `E{编号}_{变体}_{日期}`,eval json + 日志 + 可视化路径三件套齐才算完成。
- GMR 是配对数据的隐形天花板:翻译指标不追求超过 GMR 质量,物理正确性由 E7 闭环负责。

## G. 已知开放风险(继承+新增)

1. 留一拓扑泛化靠多样性解决——未证实(E5 是裁决)。
2. FSQ 收敛慢于连续,长训预算要留够;E1 的 C 组顺带给出"码本的税"的定量数字。
3. 主干完全不吃目标骨架是最激进假设;若 E5 后翻译质量仍卡,首个退让方案是主干加轻量骨架摘要 token(而非回到每本体一个主干)。
4. 约束引导的延迟是实时性最大威胁;若超预算,退路是蒸馏(引导后的轨迹当教师,微调无引导模型)。
