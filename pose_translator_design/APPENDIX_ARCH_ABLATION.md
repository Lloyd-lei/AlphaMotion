## A. 设计原则(先立法,后设计)

1. **离散是接口,连续是计算。** FSQ 码 = 存储格式、跨具身对齐的度量对象、未来大脑(VLA)的词表;生成计算走取整前的连续 latent,保证 SE3 梯度引导通路不断。FSQ 的量化 = 有界空间取整,与 diffusion 天然兼容(MAR 路线);这是当初选 FSQ 而非 VQ 的追加红利。
2. **codebook 与 diffusion 分层不冲突**:codebook 管表示,diffusion 管分布建模。唯一的耦合点是推理时梯度,由原则 1 解决。
3. **约束穿透全栈**:SE3 稀疏约束三层机制(条件注意力→扩散引导→IK 投影),精度最终由最硬的一层保证,不指望网络收敛。
4. **WBC 是评委不是下游**:可跟踪率进常规评估,运动学指标只是代理。
5. **bitter lesson 延续**:除已锁定的 twist 单独处理外,零手工结构;新结构必须先在消融中击败无结构基线才准进主线。

## B. 整体架构(三段式,B 方案)

```
        ┌──────────────────────────────────────────────────────┐
        │ ① 拓扑无关 tokenizer(预训练后冻结)                      │
        │  per-joint token(SE3-6D+相对根位置+骨长+hop图偏置        │
        │   +SigLIP关节名+rest-pose) → 图注意力编码器              │
        │   → K个查询token池化 → 连续latent z ∈ [-1,1]^d          │
        │   → FSQ取整得码(存储/度量用)                             │
        │  训练目标:全身重建 + 掩码关节重建(MAE式) + InfoNCE跨具身   │
        │  root 显式通道,不进latent                               │
        ├──────────────────────────────────────────────────────┤
        │ ② 时序主干(复用ARDY):因果transformer + 分块latent        │
        │   diffusion头,在连续z上自回归出下一块                     │
        │  条件:文本prompt ⊕ prefix(当前状态) ⊕ 约束token集         │
        │       (关节描述向量⊕时间编码⊕SE3⊕掩码⊕参考系标志,          │
        │        交叉注意力注入,训练时随机稀疏丢弃+CFG)              │
        │  推理:每个去噪步可选梯度引导(解码→FK→约束残差→修latent)     │
        │  主干不吃目标骨架 —— 具身无关性由①的码空间保证              │
        ├──────────────────────────────────────────────────────┤
        │ ③ 拓扑无关解码器:z + 目标骨架(图/rest-pose/关节名)         │
        │   → 各关节SE3 → FK                                     │
        │  末端硬投影(IK,零空间摊误差)兜底约束精度                    │
        │  输出 → 每台机器人的 WBC 跟踪策略(BeyondMimic配方)          │
        └──────────────────────────────────────────────────────┘
```

三个非显然的设计点:
- **主干具身无关**:②只看码/latent,不看目标骨架。这是"一个大脑所有身体"的前提,也是 E5 要验证的最大假设。
- **约束寻址 = 关节描述向量**:控制信号说"手腕这个语义"而不是"13号关节",跨具身零改动。
- **A(全离散GPT)与C(全diffusion)保留为对照组**,分别度量"离散的税"和"码本的税",不是主线。

预注册预测(E9):N 增大时,固定比特下泄漏下降;高比特的泄漏惩罚随 N 减弱;质量最优比特随 N 缓慢右移。

多样性三轴记账(lloyd 2026-08-03):训练集的"多样性"分三层独立计数与归因——
1. **形态**:不同机器人(12 台 GMR 清单);
2. **参数化**:同一机器人不同骨架描述(g1_30 vs g1_35);干净构造 = 同一份 qpos 分别过两棵骨架树 FK,动作严格相同,专测"码是否泄漏参数化噪声"(比跨身体泄漏更严格的不变性探针);
3. **重定向器**:厂商管线 vs GMR 管线的同源动作,单独打标签作为增强。
E5 曲线横轴只计形态数;参数化/重定向器作为独立因子分析。
背景:tokenizer 的"码本大小 vs 数据规模"在图像界有零星研究(FSQ 原文、MAGVIT-v2 词表实验),但**比特预算 × 本体多样性 × 表示不变性**这个三元组没有先例——不变性轴是本项目特有的。若曲面形状清晰,可单独成文。

### 备用架:E10 侦探驱动的容量扩张(lloyd 提议 2026-08-03,主干完成后启动)

核心:栈是沙漏——码空间要不变性(侦探=敌人,报警则挤压),解码器/WBC 要具身性(侦探=路由器+扩容触发器,报警则冻结主干加专家)。
- 解码器/WBC 侧:冻结预训练通才,新具身只加 adapter/小 MoE 专家,复用泄漏侦探当 routing 信号(免冷启动);侦探高置信识别 = 共享参数装不下该具身 = 开新专家的触发条件。先例:Progressive Nets、Any2Any(1%参数迁移)、XHugWBC(微调反超专家10%)。
- 禁区:码本/编码器侧不得按侦探信号扩容(会奖励泄漏,E0a 已证多余容量被用于记身体)。
- 预注册预测:相似具身(g1/g1_hands)会共享专家;adapter 方案在新具身上达到全参微调 95% 性能且旧具身零退化。
- 工程刺:专家数随具身线性涨(17台可控);路由错误惩罚需实测,软路由兜底。

细化 v2(lloyd 2026-08-03):
- 侦探输出 sigmoid 而非 softmax(CLIP→SigLIP 式):每具身一个二元侦探"像不像我负责的",对应专家头挂在自己的侦探上。收益:①开放世界——全体说"不像"= 新具身检测 = E10 扩容触发信号(softmax 说不出"以上都不是");②相似具身的侦探同亮→专家按亮度混合,共享是涌现的。
- **路由悖论与解法**:主线成功 = 码具身无关 = 读码的路由器失明。故路由器输入 = **目标骨架描述**(解码时恒已知、定义性具身相关),不是码;读码侦探仅保留验尸官/对抗者角色。新机器人骨架描述部分点亮相似侦探→零样本温启动。

### 备用架:E11/E12 小脑接口变体(lloyd 2026-08-03)

- **E11(SONIC式,码条件WBC)**:冻结 tokenizer,跟踪策略直接以 FSQ 码为条件(SONIC 的 UniversalTokenModule 已验证"多编码器共享FSQ码本+策略吃码"可行,但其编码器与策略共训、单一输出具身;我们的差异化=任意骨架+语义寻址)。从主线(解码参考跟踪)蒸馏启动。SE3 原始目标旁路恒保留(码有量化地板)。
- **E12(BFM桥)**:学"我们的码→BFM-Zero z 空间"映射(同段动作双侧编码配对训练)。BFM 预训练无 reward(FB 表示学习状态访问分布),推理时 reward 投影进 z 即得近优策略。定位=备选小脑(恢复/鲁棒行为),非精确跟踪;当前单具身(G1)。

E12 扩展:双小脑+仲裁器(lloyd 2026-08-03,针对"跟踪策略摔倒即OOD乱摆"):
- 结构:跟踪WBC主小脑 + BFM副小脑 + 笨仲裁器(倾角/角速度/跟踪误差三硬规则,不用学习——安全件要可验证);触发后 BFM 以"直立+低速+脚在重心下"的reward检索恢复;恢复完成→生成器以当前状态为前缀续写(架构原生支持,零新发明)。
- 三档:A 硬切换(切换期PD目标混合渐变,仿真推搡测试,指标=恢复成功率+续跟踪成功率) → B 带意图恢复(码→z桥,恢复朝原计划弯) → C 蒸馏终局(BFM当恢复数据生成器,恢复进主策略分布,运行时开关拆除)。
- 副产品:F·B 可算"状态在意图z下的访问概率"=有理论根据的OOD探测器,B档后升级仲裁器。

E12 v2(lloyd 2026-08-03,"要丝滑不要暴力"):硬切换是脚手架,终态=共享latent空间。
- 关键observation:我们的编码器对所有状态(含摔倒)处处有定义——字典已存在;缺的是①生成器不认识码空间里"回来的路"②跟踪策略价值结构非全局。
- 统一设计:FB式WBC直接以我们的块级动作latent(取整前连续)为z,FB目标学全局状态↔latent访问结构 + 模仿正则(CPR式,π_z拉向编码=z的真实动作)。分布内=精确跟踪,分布外=价值结构自然回归,丝滑是数学性质。帧码↔行为z粒度差用块latent对齐。
- 阶梯:档1(零新机器)=编码器非常规姿势增强+生成器仿真恢复轨迹增强+高频前缀重规划;档2=FB共训(研究风险:外来结构化latent当z无先例,自身够一篇论文);档3=仲裁器降级纯监控(安全冗余非架构组件)。

### 备用架:E13 时空分解码本(lloyd 2026-08-03,"单帧码本升维到多帧")

直觉:跑步=单帧手脚关系 ⊛ 关系的周期运动。三种形态:①时间残差(块慢token+帧残差,加法合成,复用ResidualFSQ机器,慢token兼任E12v2的z)②相位分解(内容环×相位×频率,WalkTheDog式,周期动作强/非周期弱)③算子分解(动力学token=作用在姿势码上的矩阵,Koopman式,latent线性化使SE3约束时间传播可解析)。
证据基础:AR似然测得码流56%时间冗余——有结构可挤。附加主张:动力学token=VLA更好词汇,换速度不碰内容。
纪律:手工结构,须打赢E1无结构基线才进主线。预注册判据:①同质量bits/块显著更低②rollout不劣③换动力学token干净变速(产品测试)。
首探针(1 GPU日):现成码流上16帧窗小AE,瓶颈=慢token+相位,慢token聚类 vs BONES动作标签——聚类混沌则全线止损。

### E17 AR+RL 后训练路线(lloyd thesis 2026-08-05)

AR 优先的复利论点:离散token=精确log概率=干净策略梯度(扩散RL需穿透去噪链,复杂度高一量级);奖励非代理而是真实(WBC可跟踪率/物理可行/任务成功/人类偏好)——接上"WBC是评委"闭环;**且RL直接治AR的冻结病**(贪心取众数→复制上一帧,奖励含能量匹配或跟踪成功即惩罚复制)。故:AR的短板正是RL能补的,扩散的长板RL难提升 → AR为主线thesis。
即刻可做的冻结修法(RL之前):温度/nucleus采样替代argmax;delta码参数化(预测变化量而非绝对码)。

### E18 3D时空patch(lloyd 猜想 2026-08-05,平行方向)

把时空特征压进单一注意力(MAGVIT-v2式)。红利:时空冗余一起压。**两个结构性冲突**:①约束粒度——patch边界与"关节×时刻"约束边界不重合,削弱SE3接口这一产品定义能力;②变拓扑——视频patch建在固定网格,我们的网格随骨架变。
**化解=分层**:帧级码保留为控制接口(约束精确到关节×时刻),时空patch建于其上供生成器提效——与E13(慢token+帧残差)是同方向的两种实现,可合并评估。

**E13↔E17 关联(lloyd 追问触发 2026-08-05)**:当前 E1A 的 AR 是最朴素形态——每帧 32×13 整数拍平,时间轴自回归,预测"下一帧绝对码"。冻结病(93.9%码复制)的根源正在于此:**绝对码的众数=复制当前帧**,平凡解唾手可得。E13 的时空分解改变预测目标的性质:预测"动力学/相位 token"(继续走)不存在"什么都不变"的平凡解可抄。故 E13 不只是压缩优化,**很可能直接治 AR 冻结**——与 E17 的 RL 修法互补(RL 从奖励侧惩罚复制,E13 从表示侧消灭平凡解)。E13 探针优先级因此上调。
