AlphaMotion·算法核心

Greenwich（空间层）× Equator（时序层）— 20 秒版 · 第 1/2 页
把任何具身的动作压成通用 token→生成 = 在 token 空间搭桥→具身在解码那一刻才决定

1Greenwich — 空间层 动作 ⇌ 通用 motion-primitive 码本，重定向消失在码本里

解码 0.2 ms / 帧 关节违规率 2% ± 0.7% 一次预训练，对所有具身生效 源具身任意：人 · 机器人 · 猫狗 · 机械臂

2Equator — 时序层 在潜空间预测码流，再交给 Greenwich 解码

自回归（masked attn）P(xi) = P(xi | x1 … xi−1)  — 只看过去，一步步猜
桥（Markov Bridge）P(xi+1 … xfinal−1 | xi, xfinal)  — 两端钉死，中间自己长出来
① 脑补只给当前 + 目标，中间过程模型自己长
② 过渡给两段动作，衔接处自动平滑
③ 插入一段动作中插入另一段，自动学会来回切换

3彩虹桥 — 跨任务换乘 两座桥焊在同一个码上

任务 y 同理：P(yi+1 … yfinal−1 | yi, yfinal)，令 xbridge = ybridge = zrainbow
两个任务只要在码流里共享一个 token，就能互相接通。这就是从走 → 跑 → 跳 → 蹲逐步扩张的机制基础： 已掌握动作的码邻居就是下一步能学的动作 —— 地平线算法（geodecity）沿着它一格格往外推。
AlphaMotion · Greenwich + Equator · 内部科普 空间：解码到任意具身，无重定向 ｜ 时序：桥式生成，两端必命中 ｜ 跨任务：共享码换乘

为什么潜空间·可以搜路径

FSQ 格点 × 拉普拉斯妖 × 地平线（geodecity）— 第 2/2 页
FSQ 把动作流形变成有限格点图→拉普拉斯妖学会每条边的概率→生成、换乘、恢复全都变成图上搜路径

4FSQ 格点 = 有限图 连通性可判定，桥不靠运气

z ∈ {1…L}D（每维只有几档的高维格子）  状态总数有限 ⇒ 潜空间是一张图，不是未知的连续地带
连续潜空间里"两个状态之间有没有路"是玄学；格点上它是可以查表回答的事实。 桥的成功率不靠祈祷，靠图的连通性——这就是"潜空间桥接连通性"。

5拉普拉斯妖 × 温度 妖 = 学到的转移核；温度 = 探索的胆量

妖：P(zt+1 | zt)  温度采样：Pτ(z′|z) ∝ P(z′|z)1/τ  τ 大 = 探索稀疏边，τ→0 = 只走主干道
① 高温做梦妖用大 τ 采样候选码流（会有幻觉）
② 物理门 + 真考仿真里筛：滑步 / 穿地 / 跳变 / 失衡全刷掉
③ 活下来的入池妖在新数据上再训练，τ 逐步下调
这就是"温度下采样学习"：做梦 → 筛选 → 长记性的闭环。妖不是天生全知，是一轮轮把幻觉换成经验。

6地平线算法 geodecity 掌握集沿邻居一圈圈外扩，永远追不上地平线

Mk+1 = Mk ∪ { w ∈ N(Mk) : 真考(πk, w) ≥ τ }  N = 码重叠的邻居；π 同步再训练，一个 generalist
两种扩张招式都是第 1 页的桥：回家（出门绕一圈回起点，安全试胆）、彩虹（借共享码跨进新家族）。 考试是真考——policy 从头执行整窗、量真实位移，不用任何滑动平均估计。

★路径搜索解锁什么 动作生成 → 动作导航

① 零样本长程编排给起点和终点，图上搜一条路——从没排练过的动作串（走→跳过障碍→翻滚→起身）一次生成，不需要该组合出现在数据里。
② 任意时刻在线换乘执行到一半改目标：当前码就是图上一个点，从这里重搜路径，动作不断、不跳帧。游戏 NPC / 遥操作接管 / 突发避障同一套机制。
③ 摔倒自恢复摔倒后的姿态也是图上一个点。恢复 = 搜一条从"倒地"回到"任意动作"的路——起身不是专门训的技能，是导航的副产品。
④ 天生跨具身路径在潜空间搜完，最后一步才解码到某台机器人：同一条路，人形 / 四足 / 机械臂全线通用，规划一次到处执行。
⑤ 可控、可审计路径是显式的码序列：可以避开危险码、卡时间预算（retiming）、事后逐码回放解释"为什么这么动"——黑盒生成做不到的。
