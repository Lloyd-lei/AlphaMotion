# ARCH V5 — 时序层完整规格（lloyd 定案 2026-08-06）

**一句话**：时序层不建模全身，只建模 **5-6 个关键关节的 SE3 轨迹**；速度不是人设档位，是**路径积分曲线**自监督学出来的 FSQ 码；其余关节由冻结的空间层补全。

---

## 一、为什么是这个设计（每条都有今天的测量支撑）

| 设计决定 | 证据 |
|---|---|
| 只建模 5-6 个关键关节 | SE3 约束扫描：5 点约束下,其余 31 个关节误差 **0.80cm**（对外部真值）；R8 逐关节内在维度：腕 **2.65 维** vs 腿 **0.84 维** |
| 抛弃固定 2 秒窗口的全局池化 | P1 全局池化只保住 22-73% 运动能量；同样 8 个单元,**关键帧插值保住 92-99%** |
| 路径与速度必须分离 | 实测同一路径快慢版 token 相似度 **0.644**（不相干动作 0.246）——当前严重纠缠 |
| 速度 = 采样率而非内容 | 频谱分析：跑步/开合跳 **33% 运动能量在 2Hz 以上**,固定 4 token/s 结构上够不到 |
| 路径积分损失取代逐帧 CE | Mathieu 2015 证明逐帧回归的最优解是时间平均；音频编解码器**无一**使用纯逐帧损失（DAC 消融：只用重建损失 SI-SDR 9.12→1.07） |
| 快动作中间可压 | 关键帧实验：出拳 **4 帧保 96%**（动力学约束死了中间路径）；太极/接触类最难压 |
| 目标状态条件化破解复读 | 帧级 AR 实测 **93.9% 复读**；给定目标后"复读"到不了目标,平凡解被结构性堵死 |

---

## 二、编码对象

**输入**：连续帧的**关键关节 SE3 状态**（不是全身 3328 维码）
- 关键关节：root、双腕、双踝、head（有灵巧手时加五指指尖）
- 每个关节：全局 6D 旋转 + 根相对位置 → 6-9 维
- **总状态 ≈ 6 关节 × 9 = 54 维**（对比现状 3328 维,**降 60 倍**）

**为什么这样降维是安全的**：其余关节由空间层从 5-6 点约束补全,实测误差 0.8cm。

---

## 三、模型架构

```
[当前关键关节SE3] [目标关键关节SE3] [prompt向量(可选)]
              ↓  双向 transformer（4-6层, d=256-512）
      ↓ Perceiver 寄存器 / 关键帧查询
   ┌──────────────┬──────────────────┐
   │ 路径 token   │  时间 token       │  ← 两条独立的 FSQ
   │ (走哪条路)   │  (花多少帧走完)   │
   └──────────────┴──────────────────┘
              ↓ 展开（关键帧 + 学习的动力学先验插值）
      每帧关键关节 SE3 → 空间层掩码补全 → 全身 → 投影 → 机器人
```

**关键点**
- **路径 token 必须对速度不变**（验收指标：同路径快慢版相似度 > 0.95,当前 0.644）
- **时间 token 自监督**：不设人工档位,由"这段路径积分花了多少帧"直接进 FSQ,格点自己分布
- 两条 FSQ 词表各约 15,625 词（6 维 × 5 档,奇数档避免浪费）
- OAT 有序前缀保留：粗 token 定路径类型,细 token 补路径细节

---

## 四、训练目标（核心创新在这里）

**主损失 = 累积弧长曲线匹配**（路径积分）
- 相邻帧 SE3 测地距离累加 → "走了多远 vs 时间"曲线
- 匹配预测曲线与真值曲线
- **一箭三雕**：终值=路径长度（走对路）、形状=时间律（速度对）、给定端点最短路径=平滑性天然满足

**辅助损失**
1. 关键关节 SE3 逐帧误差（保底,权重低）
2. 多分辨率时域损失（音频多分辨率 STFT 的动作版,尺度 1/2/4/8）
3. 速度损失（P1b 唯一验证有效的成分,保留）
4. InfoNCE 跨具身（配对身体的同片段互为正例,维持跨具身不变性）

**明确不用**：纯逐帧交叉熵作为主损失（文献判过死刑）、运动加权 CE（P1b 实测零到负收益）

---

## 五、训练方法

- **时间尺度增广**：同一段动作按 0.5×~2× 重采样,**路径 token 必须不变,时间 token 必须变**——这是分离的直接监督信号
- **目标状态采样**：训练时随机选未来某帧作为目标（跨度随机）,形成两点边值问题
- **OAT 前缀预算**：{1,2,4,8} 随机采样
- **消融期两阶段**（空间层冻结）；**生产期联合训练,但必须保留逐帧重建损失**（否则空间码失去逐帧可寻址性,SE3 接口会废）+ 保留一个冻结版做诊断基线

---

## 六、Rollout 方式

**这一轮不做 prompt→动作。做的是：给定当前状态 + 目标状态 → 生成中间动作 → 与真值对比。**

1. 取一段真值动作,首帧关键关节 SE3 = 当前状态,末帧 = 目标状态
2. 模型生成中间全部帧的关键关节轨迹
3. 空间层补全全身 → 解码到任意骨架 → 投影 → 真 mesh
4. 与真值并排

**必须展示的零样本泛化（四个维度,缺一不可）**
| 维度 | 展示方式 |
|---|---|
| **跨具身** | 同一串 token 解码到 G1/X2/A3/pnd_adam,其中 X2/A3 **不在任何数据集** |
| **跨动作** | 训练没见过的动作族（AMASS 未见片段 + kimodo/ardy 生成动作） |
| **跨速度** | 同一目标,不同时间 token → 慢速版/快速版,肉眼可辨且都合理 |
| **跨约束密度** | 只给首末 → 给中间 1 点 → 给 3 点,补全逐步收敛到真值 |

---

## 七、必须做的统计分析（一个不能少）

1. **信息熵压缩分布**：空间码在时序码本里的**利用率/重复率**——哪些码高频复用（低信息、过渡姿态）、哪些一次性（高信息、关键姿态）。**验证"信息集中在少数时刻"**
2. **路径 token 的速度不变性**：同路径快慢版相似度（验收线 >0.95）
3. **时间 token 的分布**：是否自发形成档位？与动作族/速度的对应关系
4. **词表饱和曲线**：见过的动作量 vs 新 token 出现率——**衰减则证明词表在复用**
5. **内在维度对照**：关键关节轨迹的内在维度 vs 全身（预期显著更低）
6. **频谱覆盖**：各动作族的能量有多少落在时间 token 的带宽内（当前跑步 66.5%）
7. **跨具身泄漏**：时序 token 的身体可识别率（当前 14.1%,近乎瞎猜,要保持）
8. **重建阶梯**：前缀 1/2/4/8 各自的运动能量保持率与误差

---

## 八、验收（视觉优先,数值仅作辅助）

**数值不过关但视觉过关 → 以视觉为准**（今天已两次出现数值误导：位置流渲染 bug、"跑步崩了"的误判）。

必看清单：
- 前缀 1 解出来的粗动作是否可辨认
- 同一 token 在 4 台机器人上是否做同一个动作
- 慢速版和快速版是否都自然
- 补全的中间段是否平滑无跳变

## 九、与 JEPA 的关系（lloyd 点破,2026-08-06 晚）

V5 的结构就是 JEPA:同一编码器编当前态与目标态,predictor 在 latent 空间预测,不在原始空间逐帧重建。**病也同源**——我们独立撞上并逐步解决了 JEPA 的表示塌缩在动作域的三种形态:
- "输出平均姿势"(运动能量 22%) = 塌缩教科书症状
- "解码器饿死 token"(内容占比 0.14,token 有信息没人用) = predictor shortcut(条件太强,predictor 绕过表示)
- 我们的解法与 JEPA 家族同构:条件 dropout ≈ I-JEPA 的 masking 设计;InfoNCE ≈ contrastive 反塌缩;"端点喂太饱" = V-JEPA 说的 predictor 容量/conditioning 配平

**差异化(论文主张落点)**:JEPA 表示连续、纯自监督;我们的**离散 FSQ(进词表/log-prob/可RL) + 跨具身解码落地(表示必须能变成 20 台机器人的动作)**。"离散的、物理可执行的 JEPA"文献未见。

**备药(尚未用过的 JEPA 反塌缩武器)**:EMA target encoder(目标态用慢速滑动平均编码器,切断合谋——BYOL/I-JEPA 核心件)、VICReg 方差正则(直接罚表示方差塌缩,比 InfoNCE 便宜)。V5c 若内容占比仍 <0.6,先上 EMA。
