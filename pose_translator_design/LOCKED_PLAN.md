# 锁定方案 v1 — 可提示、带 SE3 控制、原生任意拓扑、实时的动作生成器

日期:2026-08-02 · 作者:自助科研 session · 状态:方向已锁,靠实验证实/证伪后 scale

---

## 一、结论先说(TL;DR)

**不另造架构。在已有的 ARDY(NVIDIA 自回归 latent 扩散动作生成器)之上,只做一件事:把它写死的单一骨架(G1)body 表示,换成"拓扑无关"的表示,多本体联合训练,让规模和数据去学跨具身,而不是我们手工塞先验。**

这条路直接符合 bitter lesson:ARDY 已经证明了「可提示 + SE3 控制 + 实时流式」这三样在**单一本体**上能work;唯一缺的「任意拓扑」,历史上大家(包括我自己前几版设计)倾向于用手工结构(part-token、swing-twist 分解、IPA)去解决——bitter lesson 说这类手工先验长期会被"喂原始信号 + 放大模型/数据"打败。所以我们要用实验检验:**去掉手工结构、只喂原始 per-joint SE3 + 骨架图,放大 transformer,能不能学出跨拓扑。**

---

## 二、为什么是 ARDY 而不是从零

盘点发现仓库里 ARDY 已经是**训练好、正在为边缘实时部署做量化**的成熟资产,它已经交付了用户要求里的三分之三:

| 用户要求 | ARDY 现状 | 缺口 |
|---|---|---|
| 可提示(prompt) | ✅ 文本条件生成 | — |
| SE3 精确控制 | ✅ `constraints.py`:Root2D / FullBody / EndEffector,以拼接 conditioning 注入 | 只在 G1 上 |
| 实时输出 | ✅ 25fps / horizon52 / 分块异步 + 正在做 4/8bit 量化 | — |
| **原生任意拓扑** | ❌ body latent 写死单骨架 | **这是唯一真缺口,也是研究点** |

ARDY 的 token = 显式 root(全局轨迹,不进 latent,避免累积误差)+ body latent(FSQ 压缩)。**拓扑就写死在 body latent 的 tokenizer I/O 里**。把这一块换成拓扑无关,其余(自回归、控制注入、实时)原封不动复用。

---

## 三、bitter-lesson 版架构(要 scale 的东西)

三段,全部权重跨本体共享,骨架只作为"条件"输入,不作为写死的结构:

1. **拓扑无关 body tokenizer(编码器)**
   - 输入:每个关节一个 token,内容 = 该关节的 SE3(6D 旋转 + 相对根位置)+ 归一化骨长 + 图位置编码(来自 `joint_parents`)+ 关节名语义(冻结文本塔)+ rest-pose 几何(`neutral_joints`)。
   - 一个标准 transformer 编码器(带图偏置)吃可变数量关节 → 压成固定宽度的 latent(FSQ 量化)。
   - **刻意不做**:不做 part-token 分组、不做 swing-twist 拆分、不做 IPA。这些都是待检验的手工先验,默认不加。

2. **自回归时序主干(直接复用 ARDY)**
   - 在 latent 序列上做自回归生成,root 显式、body latent 隐式,两阶段去噪。
   - 文本 prompt + 动作 prompt 作为条件。SE3 约束按 ARDY 现有方式拼接注入。

3. **拓扑无关解码器**
   - 吃 latent + 目标骨架的图/rest-pose/名字,解出目标骨架每个关节的 SE3。
   - 位置由骨长 + 旋转经 FK 得到(骨长恒等满足,不需要单独 loss)。

**实时的两种模式**(必须分清,上一版混了):
- 翻译模式(有源动作驱动):编码+解码各一次,天然低延迟。
- 生成模式(纯 prompt):分块生成 + 播放缓冲区异步隐藏延迟(ARDY 已经这么做)。

## 四、决定性实验(锁定前必须先做,证实/证伪 bitter-lesson 假设)

**核心问题:一个不带手工结构的共享网络,喂原始 SE3 + 骨架图,能不能同时重建多个差异很大的真实拓扑,并泛化到没见过的本体?加了手工结构会不会更好?**

用手上已验证可加载的真实数据:
- SOMA-77(人体,BVH)+ G1-34(机器人,CSV,经 GMR 轴映射)——两个树结构差异极大的真实拓扑,都能干净加载成 `[T,J,3,3]` + FK。
- 后续 scale 用 GMR 把 SOMA 重定向到它自带的 ~17 个机器人本体,扩出更多真实拓扑。

**对照组:**
- (A) 纯拓扑无关 tokenizer(上面第 3 节的默认版,无手工结构)
- (B) A + 手工结构先验(part-token 分组 / swing-twist 输出头)——代表旧思路

**指标:**
1. 各本体单帧 SE3 重建误差(见过的本体)
2. **留一本体零样本重建**(泛化到没训过的拓扑)——这是真正测"拓扑无关"的指标
3. 单帧解码延迟(实时可行性)
4. FSQ 比特预算 × token 数联合扫描(容量刚够 vs 浪费)

**判据(bitter lesson 预测):** 随数据/规模增长,A ≥ B。若成立 → 锁 A,插进 ARDY 的 AR/控制/实时机器,开始 scale。若 B 明显更好 → 承认这个任务需要结构,回头设计最小必要结构。

## 五、跨物种(老鹰→人)怎么摆

- 同拓扑类别(人→人形机器人):有 GMR 生成的配对 GT,走监督。这是 scale 的主干。
- 跨物种(动物→机器人):**没有逐点 GT**,只能用判别器 + 语义空间对齐(SATA/ACE 路子)当训练信号,当作正则 + 定性能力,**不进定量验收指标**。动物数据(Truebones)目前未下载,属于第二阶段。

# 锁定 v2 —— 两天实验后的最终定案(2026-08-02)

实验证据见 `exp_topo/RESULTS.md`。跑了 8 个配置(local/global 目标、index、容量、梯度累积、去手指、旋转权重、FSQ),结论如下。

## 锁定的架构

**一句话:拓扑无关 tokenizer(全局帧 SE3 目标 + FSQ 离散瓶颈)→ ARDY 自回归时序主干 → 拓扑无关解码器,twist 单独处理,其余零手工结构。**

被实验支持的定案点:
1. **结构无关够用** —— 一套共享网络重建人体+机器人位置到 1–3.5cm,不需要 part-token/IPA。保持 bitter lesson。
2. **旋转目标用全局/规范帧,不用各 rig 的 local 旋转** —— 这是成败关键(g1 旋转 120°→3.4°)。
3. **FSQ 作离散瓶颈** —— 可训、可当下游 AR 词表;511 bit 有量化代价但收敛中,比特预算需扫。
4. **twist 单独处理** —— 唯一保留的结构。swing 从位置易学,twist 是位置不可观测 DOF,给它专门监督或建成分布(NIKI 式)。机器人无 twist 所以已解决;人体必须处理。
5. **实时确认** —— 2ms/帧,给 ARDY 的自回归+SE3 控制留足预算。

## Scaling Recipe(继续往下做的顺序)

1. **扩训练拓扑:2 → 20+**。用 GMR 把 SOMA 重定向到它自带的 ~17 个机器人本体,得到多本体配对。当前留一泛化只有 12cm(弱),因为只有 2 个拓扑;拓扑多样性是零样本拓扑不变性的前提。
2. **扫 FSQ 比特预算**(token 数 × 每 token 比特)画率失真曲线,选"容量刚够"的点。twist 单独通道后重扫。
3. **加 twist 头**:输出拆成 swing(6D 或方向)+ twist(标量分布),验证人体旋转从 90° 降下来。
4. **接 ARDY 时序**:把这个拓扑无关 tokenizer 的 FSQ 码接进 ARDY 的自回归主干(root 显式 + body latent 已是 ARDY 结构),SE3 约束走 ARDY 现成的 constraints 注入。
5. **规模**:tokenizer 和主干都放大(当前仅 10M),数据配比按可得 GT 分层(同拓扑监督 + 跨物种对抗/语义正则)。

## 明确的开放风险

- 跨物种(动物→机器人)无 GT,只能对抗/语义正则 + 定性,不进定量验收。Truebones 动物数据尚未下载。
- FSQ 收敛慢于连续,长训练预算要留够。
- 留一拓扑泛化目前弱,靠拓扑多样性解决,未证实。
