## 已知缺陷 / eval 时必须知道的

1. **content_share 在分母塌陷时会飞出 [0,1]**（S1 出过 1.5/3.2）——分母是"清零收益"，
   它小于 ~4cm 时该指标作废。看它之前先看 `registers buy [cm]` 绝对值。
2. `.norm(-1)` ≠ `.norm(dim=-1)`（p=-1 范数恒≈0，会伪装成完美模型）。
3. 速度不变性验收线 0.95：**没有任何版本过线**（V8 最高 0.922）。
4. V7/V8 均 `cond_drop=False`：残缺端点/单帧输入是 OOD。
5. 增广的时间扭曲局部速率失控（p99=7.5 倍速，加速度按平方放大）——所有版本共有，
   未修（保持可比性），修复方案见会话记录"rate-bounded warp"。
6. m4 的约束通路 = 草图进编码器（exam_m4.py v2）；v1 的"事后覆盖"版已证伪，勿参考。
7. 正式误差一律用 `v5_common.key_se3_err`；渲染一律 mesh（HANDOFF 纪律）。
