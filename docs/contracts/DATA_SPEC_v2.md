# UMR 数据工厂 数据规格 v2（lloyd 2026-10-04 定）

## 1. 接触的定义（取代"整片脚底贴地"的要求）
机器人脚没有脚背脚趾，很多时候只是一个点/一条边碰地，这是允许的。但这个小面积接触必须是"实"的（solid）：
- **真碰到**：该区域（脚、手、膝、躯干…）稠密表面点（>= 4096/台）里，最低点离地（或离物体表面）在 [0, 1.0 mm]。至少 1 个点即可，不要求整片贴平。
- **不穿**：任何点都不能低于地面/进入物体 > 0.5 mm；同时用 MuJoCo 碰撞几何复核（地面、物体、自身非相邻部件）。
- **不滑**：接触期间，接触点在世界系（物体接触则在物体坐标系）里的切向速度 < 1 cm/s（接触点锁定 latch，换支撑点只能在接触段之间发生）。
  - **1011 lloyd 放宽**："不要太严格，有些动作本身就应该打滑"。改为：人体同一区域本身在滑（转身、碾脚、滑步等）时，机器人跟着滑是合法的——这些帧**保留**，打上"跟随人体打滑"标记并记录双方滑速，不再剔除；只有"人没滑、机器人滑了"（机器人自己溜冰）才算违规帧。允许脚绕接触点转动/滚动（脚跟→脚尖）。
- **不闪**：接触段最短 3 帧（进入 < 1 mm、离开 > 2 mm 的滞回）。
- **和人一致**：人体（SMPL-X 表面点、同一把尺子、按会话校准的地面）某区域在接触 → 机器人对应区域必须"实接触"；人体该区域离地 > 2 cm → 机器人对应区域也要离开（> 5 mm）。物体同理。
- 做不到的帧：标记并从数据集剔除，报精确数量，绝不悄悄保留。

## 2. 地面坐标
所有输出一律以"校准后的地面 = z 0"为准（输出前减掉 floor），并在文件里另存 floor 原值。禁止一部分代码用原始 z=0、一部分用校准地面。

## 3. 最终数据内容（每个 片段×机器人）
- 骨架：root 位姿 + 关节角（qpos），fps=30。
- 点云：机器人稠密表面点资产（静态，绑定到连杆，每台一份，含区域/垫片标签）；逐帧位置由 qpos 正向运动学算出（不逐帧存坐标，省空间）。
- 点云上的接触信息（逐帧）：
  - 每个接触点的索引（稀疏存储：只存离地/离物体 <= 1 mm 的点）+ 接触对象（地面 / 物体 id）；
  - 离接触面 < 2 cm 的点的距离（量化，稀疏）；
  - 区域级标签：地面接触、物体接触、打滑、穿透深度。
- 人体：SMPL-X 参数 + 人体表面点上的同类接触标签（同一把尺子）。
- 物体：网格 id + 逐帧 6D 位姿。
- 质检：每帧 flags；每段统计（最深穿透、接触一致率、打滑率、剔除帧数）。
