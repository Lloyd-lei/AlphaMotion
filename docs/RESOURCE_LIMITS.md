# 资源上限（lloyd 2026-10-07：USB WiFi 网卡在整机高负载时会掉线，必须限流）

所有任务（包括子代理）必须遵守：
- **CPU**：只用 0-15 号核（32 线程里的一半）。启动重活一律 `taskset -c 0-15 nice -n 10 ...`；线程数设 `OMP_NUM_THREADS=2 MKL_NUM_THREADS=2`；同时最多 6 个 CPU 重进程。
  （`scripts/throttle_guard.sh` 每 20 秒会把漏网的进程自动绑核降级，但不要依赖它。）
- **GPU**：同一时间最多一个"重 GPU 任务"（功耗目标 < 350 W，利用率目标 < 70%）；批大小从小往上加，不要一上来就跑满。GPU 格式转换常驻任务已降到 256 lanes。
- **内存**：无交换区，单进程树 < 20 GB；开重活前看 `free -g`，可用 < 15 GB 就等。
- **网络**：下载走 aria2c/curl，连接数 ≤ 16。
- 如果发现 `logs/throttle.log` 里 net=down，先停下自己的重活，等网络恢复再继续。
